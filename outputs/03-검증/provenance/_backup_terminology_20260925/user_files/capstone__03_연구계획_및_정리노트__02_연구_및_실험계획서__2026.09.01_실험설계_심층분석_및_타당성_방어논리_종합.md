# 1. [1번 영역] 실험 과제(Task) 선정의 임상적·신경생리학적 당위성

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        임상 평가 및 중재 4대 표준 과제 계층 구조                       │
├──────────────────┬──────────────────────────────┬──────────────────────────────────────┤
│ 과제 구분        │ 동작 명칭 및 대상 물체       │ 신경생리학적·임상적 평가 목적         │
├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤
│ **Task 1**       │ 맨손 최대 쥐기 및 펴기       │ 외력 저항 없는 순수 능동 가동범위    │
│ (Free Hand)      │ (No Object, Free Flex/Ext)   │ (TAROM Baseline) 및 손가락 분리도     │

├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤

├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤
│ **Task 4**       │ Master-Slave 미러테라피      │ 양측성 훈련(BAT) 및 거울신경세포     │
│ (Mirror Therapy) │ (Bilateral Mirror Tracking)  │ 자극을 통한 즉각적 가동범위/경직 개선│
```

### 1.1 왜 4가지 과제(Task 1~4)의 계층적 사다리 구조인가?
1. **임상 평가 사다리 구축 (Clinical Ladder)**:
   * **진단(Baseline, Task 1)** ➡️ **기초 일상동작(Power Grasp, Task 2)** ➡️ **고난도 협응(Precision/Opposition, Task 3)** ➡️ **로봇 중재(Intervention, Task 4)**로 이어지는 완결된 임상 재활 사이클을 형성합니다.
2. **손 전용 브룬스트롬(Brunnstrom Hand Stages 3 ➡️ 5)과의 1:1 매핑**:
   * **Stage 3 (집단 굴곡기, Mass Flexion)**: 자발적으로 주먹을 쥘 수는 있으나 스스로 손가락을 펴지(Release/Extension) 못함 $\rightarrow$ **Task 1**에서 굴곡-신전 불균형 및 굴곡 공동운동(Flexor Synergy) 정도를 정량화.
   * **Stage 4 (공동운동 이탈기)**: 굵은 물체를 감싸 쥘 수 있고 엄지의 부분 신전이 가능 $\rightarrow$ **Task 2**에서 외재 굴곡근 기반 파워 파지(Power Grasp) 안정성 평가.
   * **Stage 5 (독립 조작 및 3D 대립기)**: 구형 물체 파지 및 자발적 손가락 전 범위 신전(Release) 가능 $\rightarrow$ **Task 3**에서 엄지 대립근(Opponens pollicis) 협응 및 개구 조절능력 평가.
3. **평가(Assessment)와 치료(Intervention)의 단일 플랫폼 융합**:
   * 단순 관찰·진단에 그치지 않고, **Task 4(미러테라피)**를 통해 공압 로봇 중재 전/후(Pre vs Post)의 운동학적 개선(TAROM 증가, SPARC 매끄러움 향상)을 동일 시스템에서 즉각 실증합니다.

### 1.2 Task 1(맨손 최대 쥐기/펴기)의 필수성 및 신경생리학적 근거
1. **외력 및 지지 배제 (순수 내인성 신경근 조절력 측정)**:
   * 물체를 쥐는 순간 손가락은 물체 표면으로부터 '기계적 지지(Mechanical Support)'와 '촉각 피드백(Tactile Cue)'을 받습니다.
   * 환자가 물체에 손을 얹어 지탱하는 보상 작용(Compensatory strategy)을 완전히 배제하고, 오직 대뇌 피질-척수로(Corticospinal Tract)의 자발적 신경 흥분만으로 생성된 **순수 능동 가동 범위(TAROM Baseline)**를 측정하려면 맨손 과제가 필수적입니다.
2. **손가락 개별 독립 분리도(Finger Individuation Index) 정량화**:
   * 뇌졸중 후 상위운동신경세포(UMN) 손상 시 나타나는 대표적 병적 현상은 **'연합 반응(Involuntary Enslaving)'**입니다. 즉, 검지만 굽히려 해도 4, 5지가 함께 굽혀지는 현상입니다.
   * 물체 접촉 저항이 없는 상태에서 5개 손가락 관절 각도의 시계열 상호상관(Cross-correlation) 행렬을 분석해야 순수 협응 분리도를 정밀 측정할 수 있습니다.
3. **무가림(Occlusion-free) 해부학적 관절각 캘리브레이션**:
   * 물체에 의한 가림이 전혀 없는 상태에서 환자의 해부학적 최대 굴곡/신전 각도를 획득하여, 이후 Task 2, 3의 물체 접촉 시 손끝 가림 보정 필터(Adaptive Occlusion Hold)의 기준치($\theta_{hold}$)로 활용합니다.

### 1.3 제외된 파지 형태(Pinch, Key Grasp 등)에 대한 방어 논리
```
┌─────────────────┬──────────────────────────────────┬──────────────────────────────────┐
│ 파지 유형       │ 임상적 한계 및 제외 사유         │ 비전/로봇 공학적 제외 사유       │
├─────────────────┼──────────────────────────────────┼──────────────────────────────────┤
│ **Tip Pinch**   │ • FMA 56~66점(최후기 회복) 전용  │ • 손끝 접촉 시 랜드마크 겹침     │
│ (손끝 집기)     │ • 중등도 환자(20~55점) 수행 불가 │   (Self-occlusion) 및 ID 스위칭  │
├─────────────────┼──────────────────────────────────┼──────────────────────────────────┤
│ **Key Grasp**   │ • 엄지를 검지 측면에 누르는 2D   │ • 검지 요측 가림으로 MCP/PIP     │
│ (측면 집기)     │   단순 운동으로 5지 협응 반영 부족│   정밀 3D 각도 산출 불가         │
├─────────────────┼──────────────────────────────────┼──────────────────────────────────┤
│ **Disk Grasp**  │ • 평면 원판 파지는 손목 신전각에 │ • 단안 카메라 앵글 상 손가락     │
│ (원판 파지)     │   극도로 민감하여 오차 발생      │   관절 노드 은폐율 70% 초과      │
└─────────────────┴──────────────────────────────────┴──────────────────────────────────┘
```
* **결론**: 본 연구가 선정한 **원통형 파지(Task 2)**와 **구형 파지(Task 3)**는 5개 손가락의 3차원 궤적이 공간상 명확히 분리되어 광학식 비전 계측의 신뢰도를 극대화하며, 공압 벨로우즈 액추에이터의 굴곡 보조 메커니즘과 완벽히 일치합니다.

# 2. [2번 영역] 대상 물체(Object) 규격 및 물리량 선정의 기하학적·인체측정학적 근거

```
┌──────────────────┬──────────────────┬──────────────────────────────────────────────────┐
│ 물체 구분        │ 물리적 규격      │ 임상적·생체역학적 선정 당위성                    │
├──────────────────┼──────────────────┼──────────────────────────────────────────────────┤
│ **원통형 물체**  │ 직경 5.0 cm      │ • 성인 손 크기(17~19cm)의 최적 파워 파지 직경    │
│ (Task 2)         │ 높이 12.0 cm     │ • PIP/DIP 관절 60~80° 이상적 굴곡 유도           │
│                  │ 무게 150 g       │ • **ARAT Subtest 2 (Grip)** 표준 원통 규격 준용  │
│                  │                  │ • 일상생활(ADL) 컵, 캔(직경 5.2cm), 손잡이 일치  │
├──────────────────┼──────────────────┼──────────────────────────────────────────────────┤
│ **구형 물체**    │ 직경 7.0 cm      │ • **FMA-UE 손 파트 표준 규격** (야구공/테니스공) │
│ (Task 3)         │ 무게 100 g       │ • 엄지 대립근(Opponens pollicis) 3D 회전 유도    │
│                  │                  │ • **Jeannerod 파지 법칙**: MGA 이상 결손(과소/   │
│                  │                  │   과대 개구)이 가장 극명히 판별되는 임계 직경    │
└──────────────────┴──────────────────┴──────────────────────────────────────────────────┘
```

### 2.1 원통형 물체: 왜 직경 5.0cm / 높이 12cm / 무게 150g인가?
1. **인체측정학(Anthropometry) 및 파지 기하학**:
   * 한국인 성인 평균 손 길이($L_{hand} \approx 17.5 \sim 18.8\text{cm}$) 기준, 직경 5.0cm는 원주 길이 $C = \pi d \approx 15.7\text{cm}$입니다.
   * 이는 중수지절관절(MCP) $45^\circ$, 근위지간관절(PIP) $70^\circ$, 원위지간관절(DIP) $40^\circ$의 이상적 굴곡 각도를 유도하여 손바닥과 수지 전체가 물체를 감싸는 **전형적인 원통형 파워 파지(Cylindrical Power Grasp)**를 형성합니다.
2. **임상 평가 도구(ARAT)와의 표준화**:
   * 뇌졸중 상지 기능 평가의 국제 표준인 **ARAT (Action Research Arm Test) Subtest 2 (Grip)**의 표준 원통형 블록 규격(직경 5.0cm)을 준용하여 공인 임상 데이터와의 직접 비교가 가능합니다.
3. **ADL(일상생활활동) 적합성**:
   * 음료수 캔(직경 5.2cm), 종이컵(직경 5.0~7.0cm), 보온병, 문손잡이 등 일상 도구와 동일한 파지 역학을 재현합니다.
4. **무게(150g) 설정 이유**:
   * 편마비 환자의 상지 피로도를 최소화하면서도, 손에 쥐었을 때 고유수용감각(Proprioception)을 자극할 수 있는 최소 임계 질량(150g)으로 설정했습니다.

### 2.2 구형 물체: 왜 직경 7.0cm / 무게 100g인가?
1. **FMA-UE 공인 규격 준용**:
   * **Fugl-Meyer Assessment (FMA-UE)** 수부 평가의 'Spherical Grasp' 검사 도구(야구공/테니스공 직경 6.5~7.0cm) 표준 규격을 그대로 적용했습니다.
2. **엄지 대립근(Opponens pollicis)의 3D 공간 회전 유도**:
   * 평면 파지와 달리 3차원 구형 물체는 엄지손가락이 손바닥 안쪽으로 $35^\circ$ 이상 대립(Opposition)하고 제1배측골간근(1st Dorsal Interosseous)이 외전되어야만 안정적으로 지탱할 수 있습니다.
3. **Jeannerod의 파지 전 성형(Pre-shaping) 법칙 및 MGA 민감도**:
   * 신경운동학 법칙(Jeannerod, 1984)에 따르면 정상인은 물체 직경 $D_{obj} = 7.0\text{cm}$에 접근할 때 접촉 전 최대 개구폭 $MGA \approx 8.5 \sim 10.5\text{cm}$ (물체 크기의 1.2~1.5배)를 형성합니다.
   * 구 직경이 7.0cm일 때 뇌졸중 환자의 대표적인 파지 결손인 **MGA 과소 형성(Hypometria, $R_{MGA} < 1.1$)** 및 **MGA 과대 형성(Hypermetria, $R_{MGA} > 1.8$)**이 가장 높은 통계적 변별력($p < 0.001$)으로 검출됩니다.

### 2.3 물체 표면 재질 및 광학 특성
* **무광(Matte Finish) 코팅**: 카메라 적외선(IR) 및 실내 조명의 정반사(Specular Highlight)로 인한 MediaPipe 랜드마크 지터(Jitter)를 방지하기 위해 반사율 5% 미만의 무광 표면을 적용했습니다.
* **마찰계수 최적화**: 마찰계수 $\mu \approx 0.6$의 무광 고밀도 EVA 폼/플라스틱을 사용하여 물체 미끄러짐으로 인한 측정 노이즈를 차단했습니다.

# 3. [3번 영역] 비교 기준(Ground Truth) 벤치마크 및 피험자 대조군 설계

### 3.1 골드 스탠다드(Gold Standard) 벤치마크
1. **수기/전자 관절각도계 (Goniometer)**:
   * 임상 현장에서 사용되는 고니오미터로 측정한 14개 관절의 정적 굴곡각을 Ground Truth로 설정.
   * 비접촉 광학식 계측값과의 일치도 검증: **급간내상관계수 $ICC(2,1) \ge 0.85$** 및 **Bland-Altman 95% LoA** 산출.
2. **임상 평가 척도 (FMA-UE & Hand Brunnstrom)**:
   * 재활의학과 전문의/물리치료사 2인이 독립적으로 측정한 FMA-UE 손 파트 점수(0~14점) 및 손 브룬스트롬 단계(1~6단계)를 타깃 레이블로 활용하여 AI 예측 정확도(RMSE < 1.2점, 분류 정확도 > 90%)를 검증.

### 3.2 피험자군 비교 설계 (총 $N=30$)
```
┌───────────────────────────────────────┬───────────────────────────────────────┐
│ 정상 대조군 (Healthy, $N=15$)         │ 뇌졸중 편마비 환자군 (Patient, $N=15$)│
├───────────────────────────────────────┼───────────────────────────────────────┤
│ • 만 20세 이상 성인 (남/여)           │ • 뇌경색/뇌출혈 편마비 진단자 (발병 > 3개월)│
│ • 신경계/근골격계 상지 질환 병력 없음  │ • **FMA-UE 점수: 20 ~ 55점** (경도~중등도)│
│ • 비접촉 시스템 기기 신뢰도(Test-     │ • **Brunnstrom Hand: 3 ~ 5단계**      │
│   Retest) 및 표준 정상 운동학 데이터  │ • **MMSE(인지기능): 24점 이상** (지시 수행)│
└───────────────────────────────────────┴───────────────────────────────────────┘
```
* **제외 기준(Exclusion Criteria)**:
  * 관절 구축(Contracture, 수동 가동범위 50% 이상 제한).
  * 심각한 감각 상실(Nottingham Sensory Assessment 결손) 또는 편측 무시(Hemispatial Neglect).
  * 수부 개방성 상처 또는 피부 질환.
* **중재 전/후(Pre vs Post) 비교 설계**:
  $$\Delta \text{Metric} = \text{Metric}_{\text{Post-Intervention}} - \text{Metric}_{\text{Pre-Intervention}}$$
  * 미러테라피 1회 세션(15분) 전후의 환측 손 TAROM, SPARC, MGA 변화를 **대응표본 t-검정(Paired t-test)**으로 검증.

### 3.3 기존 착용형 센서 장갑(Flex Sensor Glove) 대비 비접촉 시스템의 5대 우위성
| 비교 항목 | 기존 착용형 센서 장갑 (Flex/IMU Glove) | **본 연구의 비접촉 비전 시스템 (Webcam/RealSense)** |
| :--- | :--- | :--- |
| **1. 착용 부담** | 손가락마다 센서/배선 장착, 착용 피로감 큼 | **완전 비접촉 (카메라 앞에 손을 올리면 즉시 계측)** |
| **2. 촉각 보존** | 두꺼운 센서/장갑이 물체 접촉 감각을 차단 | **맨손 본연의 고유수용감각 및 자연스러운 파지 보존** |
| **3. 크기 적응성** | 장갑 치수(S/M/L) 불일치 시 센서 위치 왜곡 | **SVD 손 크기 정규화로 성인/아동 체격 불변 적용** |
| **4. 신뢰성/수명** | 반복 굴곡 시 센서 마모, 드리프트(Drift) 발생 | **광학 기반 기하학적 3D 연산으로 드리프트 전무** |
| **5. 감염 관리** | 다수 환자 착용 시 땀/오염 소독 어려움 | **비접촉이므로 병원 내 교차 감염 원천 차단** |

# 4. [4번 영역] 정량 운동학 지표(Metrics) 선정의 수학적·생체역학적 근거

### 4.1 3D 관절각 산출 ($\theta$)
3차원 랜드마크 $P_a, P_b, P_c \in \mathbb{R}^3$에 대해 중심 관절 $P_b$를 꼭짓점으로 하는 두 벡터 $\vec{v}_{ba} = P_a - P_b, \vec{v}_{bc} = P_c - P_b$ 정의:
$$\theta = \arccos \left( \frac{\vec{v}_{ba} \cdot \vec{v}_{bc}}{\|\vec{v}_{ba}\| \|\vec{v}_{bc}\|} \right) \times \frac{180^\circ}{\pi}$$
* 14개 관절각 산출: 엄지(MCP, IP), 검지/중지/약지/소지(MCP, PIP, DIP).

### 4.2 총 능동 가동 범위 (TAROM, Total Active Range of Motion)
$$\text{TAROM} = \sum_{f \in \{\text{Thumb, Index, Middle, Ring, Pinky}\}} \left( \max_{t} \theta_f(t) - \min_{t} \theta_f(t) \right) \quad (^\circ)$$
* **선정 근거**: 미국수부외과학회(ASSH) 표준 지표로, 14개 개별 관절의 분산된 각도를 전수부 가동성 종합 단일 척도로 집약. 정상인($\approx 450^\circ$) 대비 환자($< 250^\circ$)의 가동성 결손을 한눈에 정량화.

### 4.3 정규화 최대 개구율 (MGA Ratio %)
$$\text{MGA Ratio} = \max_{t \in [t_{\text{reach}}, t_{\text{grasp}}]} \left( \frac{\|P_{\text{Thumb\_TIP}}(t) - P_{\text{Index\_TIP}}(t)\|}{\|P_{\text{Middle\_MCP}} - P_{\text{Wrist}}\|} \right) \times 100 \quad (\%)$$
* **선정 근거**: 절대 픽셀이나 cm 단위는 카메라 거리(Z축) 및 피험자 체격에 따라 왜곡됨. 손바닥 기준 길이($\|P_{\text{Middle\_MCP}} - P_{\text{Wrist}}\|$)로 나눔으로써 **피험자 체격 및 거리 불변성(Scale & Distance Invariant)** 완벽 확보.

### 4.4 운동 매끄러움 지표: SPARC (Spectral Arc Length)
손가락 굴곡 각속도 프로파일 $v(t) = \frac{d\theta}{dt}$에 대해 60Hz 리샘플링 및 $N=4096$ Zero-padding 푸리에 변환 $V(\omega) = \mathcal{F}\{v(t)\}$, 정규화 스펙트럼 $\hat{V}(\omega) = \frac{V(\omega)}{V(0)}$ 적용:
$$\text{SPARC} \equiv -\int_0^{\omega_c} \sqrt{\left(\frac{1}{\omega_c}\right)^2 + \left(\frac{d\hat{V}(\omega)}{d\omega}\right)^2} d\omega$$
* $\omega_c = \min(\omega_{\text{max}}, \min\{\omega \mid \hat{V}(\omega) \le 0.05 \max \hat{V}\})$ (유효 5% 적응형 컷오프 주파수).
* **선정 근거 (단순 Jerk / Peak Count 대비 압도적 우위성)**:
  1. **무차원(Dimensionless) 척도**: 동작 소요 시간이나 동작 크기에 영향을 받지 않음 (*Balasubramanian et al., IEEE TNSRE 2015*).
  2. **경직/단속적 운동 감지**: 부드러운 단일 벨 모양 속도일수록 0에 수렴하며, 뇌졸중 환자의 떨림 및 다중 하위운동(Submovements) 발생 시 음수 절대값이 크게 증가하여 마비 중증도를 민감하게 포착.

### 4.5 양손 대칭도 지수 ($SI$) 및 시간 지연 ($\tau_{lag}$)
$$SI = \left( 1 - \frac{\sum_{i=1}^5 |\Delta\theta_{i}^{\text{건측}} - \Delta\theta_{i}^{\text{환측}}|}{\sum_{i=1}^5 \Delta\theta_{i}^{\text{건측}}} \right) \times 100\%, \quad \tau_{lag} = \arg\max_\tau \int v_{\text{건측}}(t) v_{\text{환측}}(t + \tau) dt$$
* **선정 근거**: 미러테라피 중 건측과 환측의 실시간 운동 동기화 일치도 및 신경근/공압 지연 정량화.

# 5. [5번 영역] 신호 처리 파이프라인 및 알고리즘 최적화의 수학적 증명

### 5.1 손바닥 SVD 정준화 (SVD Hand Normalization) 수학적 증명
1. **중심화 (Centering)**: 손바닥 6개 랜드마크 $P_i \in \mathbb{R}^{6 \times 3}$ ($i \in \{0, 1, 5, 9, 13, 17\}$)의 무게중심 $\bar{P} = \frac{1}{6}\sum P_i$을 원점으로 이동:
   $$\tilde{P}_i = P_i - \bar{P}$$
2. **특잇값 분해 (SVD)**: $3 \times 3$ 공분산 행렬 $C = \tilde{P}^T \tilde{P}$에 SVD 적용:
   $$C = U \Sigma V^T$$
   여기서 우측 특이벡터 행렬 $V = [\vec{v}_1, \vec{v}_2, \vec{v}_3]$은 손바닥 평면의 3차원 주축 기저벡터(Basis)를 형성.
3. **정준 좌표 변환 및 스케일 정규화**:
   $$P_{\text{canonical}} = \frac{(P - \bar{P}) V}{\|P_{\text{Middle\_MCP}} - P_{\text{Wrist}}\|}$$
4. **시점 불변성 증명**: 두 벡터 $\vec{u}, \vec{w}$ 간의 각도 $\theta = \arccos(\frac{\vec{u} \cdot \vec{w}}{\|\vec{u}\|\|\vec{w}\|})$는 직교 회전 변환 행렬 $V$와 스칼라 스케일 $S$에 대해 다음이 성립:
   $$\frac{(S \vec{u} V) \cdot (S \vec{w} V)}{\|S \vec{u} V\| \|S \vec{w} V\|} = \frac{S^2 (\vec{u} V V^T \vec{w}^T)}{S^2 \|\vec{u}\| \|\vec{w}\|} = \frac{\vec{u} \cdot \vec{w}}{\|\vec{u}\| \|\vec{w}\|}$$
   따라서 **피험자가 카메라를 비스듬히 보거나 손을 3차원으로 기울여도 순수 내인성 해부학적 굴곡각이 100% 보존**됩니다.

### 5.2 One-Euro 필터 파라미터 최적화
* **수식**:
  $$\hat{x}_k = \alpha x_k + (1 - \alpha) \hat{x}_{k-1}, \quad \alpha = \frac{1}{1 + \frac{1}{2\pi f_c T_e}}, \quad f_c = f_{c,\text{min}} + \beta |\dot{x}_k|$$
* **튜닝 파라미터**:
  * **XY 평면 (고속 추종)**: $f_{c,\text{min}} = 0.4\text{Hz}, \beta = 0.08, d_{\text{cutoff}} = 1.2$ $\rightarrow$ 정적 지터 완전 제거 및 동적 지연 5ms 미만 달성.
  * **Z축 깊이 (노이즈 억제)**: $f_{c,\text{min}} = 0.15\text{Hz}, \beta = 0.002, d_{\text{cutoff}} = 0.8$ $\rightarrow$ 단안 비전의 취약한 Depth 떨림을 강력 억제.

### 5.3 파지 중 Adaptive Occlusion Hold 필터링
물체 접촉 시 손끝 가림 발생($\text{visibility} < 0.5$) 시 오검출 급변을 방지하는 지수 유지 모델:
$$\hat{\theta}(t) = \begin{cases} 
\theta_{\text{raw}}(t), & \text{if } \text{visibility}(t) \ge 0.5 \\
\alpha \cdot \hat{\theta}(t-1) + (1 - \alpha) \cdot \theta_{\text{hold}}, & \text{if } \text{visibility}(t) < 0.5 \text{ and } t - t_{\text{loss}} \le 3.0\text{s}
\end{cases}$$
* 직전 유효 파지각($\theta_{\text{hold}}$)을 3초간($\alpha=0.98$) 유지하여 물체 파지 구간 데이터 무결성 보장.

### 5.4 Reach vs Grasp 자동 분할 알고리즘 (5% Peak Velocity Threshold)
1. 5개 손가락 평균 각속도: $\omega_{\text{avg}}(t) = \frac{1}{5}\sum_{i=1}^5 |\frac{d\theta_i}{dt}|$
2. 피크 속도 검출: $\omega_{\text{peak}} = \max \omega_{\text{avg}}(t)$
3. **Movement Onset ($t_{\text{reach}}$)**: $\min \{ t \mid \omega_{\text{avg}}(t) \ge 0.05 \omega_{\text{peak}} \}$
4. **Grasp Onset ($t_{\text{grasp}}$)**: $\min \{ t > t_{\text{peak}} \mid \omega_{\text{avg}}(t) \le 0.05 \omega_{\text{peak}} \text{ and } \Delta\theta_{\text{avg}} < \epsilon \}$

3. **초경량 구조**: 모터 대비 초경량 패브릭/실리콘 구조로 근위부 어깨/팔꿈치 피로도 최소화.

* 영상 획득(60fps, 16.6ms) + MediaPipe 추론(15ms) + SVD/필터 연산(2ms) + 시리얼 전송(1ms) + 솔레노이드/압축공기 충진(35ms) = **총 69.6ms**.

# 7. [7번 영역] 2-Stage AI (시계열 모델) 및 VLM 멀티모달 아키텍처 채택 근거

```
[Phase 1: 정량 운동학 AI (1D-CNN + BiLSTM)] ──► [FMA 점수 / Brunnstrom 단계 확정]
                                                        │
                                                        ▼
[Keyframe 시퀀스 (Reach-Preshape-Grasp)] ──────► [Phase 2: VLM 멀티모달 추론] ──► [📄 임상 소견서 자동 생성]
```

### 7.1 왜 바로 End-to-End VLM을 쓰지 않는가?
1. **의료 환각(Hallucination) 원천 차단**:
   * 대형 멀티모달 모델(VLM)에 영상만 주고 "FMA 점수를 매겨라"고 하면 매번 달라지는 임의의 수치를 생성(Hallucination)하여 의료기기로서의 신뢰성을 상실합니다.
2. **수학적 정량 점수와 자연어 해석의 역할 분리**:
   * **1단계 (시계열 모델)**: 정밀 운동학 시계열 데이터($T \times 24$)로부터 오차 1점 미만의 **수학적 정량 점수(FMA 점수, Brunnstrom 단계)**를 확정.
   * **2단계 (VLM)**: 확정된 정량 점수와 핵심 시점 이미지를 결합하여 **의사/치료사를 보조하는 설명 가능한(Explainable) 임상 소견서 리포트**를 생성.

### 7.2 Phase 1 시계열 모델 아키텍처 명세
* **입력 텐서**: $X \in \mathbb{R}^{300 \times 24}$ (10초 @ 30fps 시계열 피처).
* **네트워크 구조**: `1D-CNN (Local Feature)` ➡️ `Bi-LSTM (Temporal Dependency)` ➡️ `Attention Pooling` ➡️ `Multi-Head Output`.
  * **Head 1 (분류)**: Brunnstrom Hand 3~5단계 분류 (Softmax, Cross-Entropy Loss).
  * **Head 2 (회귀)**: FMA-UE 손 파트 점수 추정 (Linear, Smooth L1 Loss).
  * **Head 3 (이상 감지)**: 경직/비정상 궤적 여부 (Sigmoid, BCE Loss).

# 8. [8번 영역] 통계적 검증 계획의 엄밀성 및 표본 크기($N=30$) 산출 근거

### 8.1 표본 크기($N=30$) 산출 근거 ($G^*\text{Power}$ 3.1 분석)
* **분석 파라미터**:
  * 검정 기법: Paired t-test (미러테라피 중재 전/후 TAROM 변화 검증)
  * 유의수준 ($\alpha$): $0.05$
  * 목표 검정력 ($1-\beta$): $0.80$ (80%)
  * 중간 효과 크기 (Cohen's $d$): $0.65$
  * **산출된 최소 표본 수**: **21명**
* **최종 표본 설계**: **정상 대조군 15명 + 뇌졸중 환자군 15명 = 총 30명** (중도 탈락율 20% 고려 및 서브그룹 분석 검정력 80% 이상 확보).

### 8.2 통계적 분석 기법 명세
1. **동시 타당도 (Concurrent Validity)**:
   * 고니오미터 vs 비접촉 시스템 간 **급간내상관계수 $ICC(2,1)$** 산출 ($ICC \ge 0.85$ 목표).
   * **Bland-Altman 95% 일치 한계(Limits of Agreement, $\text{Bias} \pm 1.96\text{SD}$)** 도표화.
2. **검사-재검사 신뢰도 (Reliability) & 측정 오차**:
   * **표준측정오차(SEM)**: $\text{SEM} = \text{SD} \times \sqrt{1 - \text{ICC}}$
   * **최소감지가능변화량(MDC)**: $\text{MDC}_{95} = 1.96 \times \sqrt{2} \times \text{SEM}$
3. **임상적 상관성 및 치료 유효성**:
   * AI 산출 지표(SPARC, MGA, TAROM)와 실제 FMA-UE 점수 간의 **피어슨/스피어만 상관분석 ($r > 0.60, p < 0.05$)**.
   * 미러테라피 전후 개선 비교를 위한 **대응표본 t-검정(Paired t-test)** 및 **Wilcoxon 부호순위검정**.
