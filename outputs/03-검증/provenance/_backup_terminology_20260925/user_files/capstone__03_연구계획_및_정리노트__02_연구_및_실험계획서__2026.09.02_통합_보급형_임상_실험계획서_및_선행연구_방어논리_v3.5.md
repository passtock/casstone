## 1. 연구 개요 및 핵심 가치 (Research Overview & Core Value)

### 1.1 연구 배경 및 학술적 포지셔닝
기존의 뇌졸중 상지 재활 및 평가 연구는 크게 세 가지 방향으로 분절되어 발전해 왔습니다:
1. **수기 임상 평가(FMA, ARAT 등)**: 치료사의 주관적 관찰(0/1/2점)에 의존하여 시간 소모가 크고 미세한 회복 추적에 한계가 있음.
2. **고가 모션캡처/로봇 진단 연구**: VICON 3D 카메라나 거대 외골격 로봇을 사용하여 정밀도는 높으나, 수억 원대의 비용과 부피로 인해 실제 임상 및 가정 보급이 불가능함.
3. **분절된 중재 연구**: 로봇 글러브 연구는 제어에만 집중하고 정량 평가 기능이 없으며, 비전 평가 연구는 단순 진단에 그치고 치료 기능이 부재함.

## 2. 3대 표준 평가 과제 및 1대 중재 과제 설계 (Task Design)

환자의 근피로도를 최소화하면서 FMA-UE 손 파트(7개 항목)와 ARAT의 핵심 파지 영역을 100% 대변하기 위해 **[맨손 1개 + 표준 물체 2개 + 미러테라피 중재 1개]의 4대 과제 체계**를 구축합니다.

```
┌──────────────────┬──────────────────────────────┬──────────────────────────────────────┐
│ 과제 구분        │ 동작 명칭 및 대상 물체       │ 신경생리학적·임상적 평가 목적         │
├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤
│ **Task 1**       │ 맨손 최대 쥐기 및 펴기       │ 외력 배제 순수 능동 가동범위(TAM)    │
│ (Free Hand)      │ (No Object, Free Flex/Ext)   │ 및 손가락별 독립 분리도(연합반응)    │
├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤
│ **Task 2**       │ 원통형 물체 파지             │ 외재 굴곡근(FDS/FDP) 파워 파지 능력   │
│ (Cylinder Grasp) │ (직경 5.0cm, 높이 12cm 원통) │ 및 기초 일상생활동작(ARAT Grip 표준) │
├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤
│ **Task 3**       │ 구형 물체 파지               │ 엄지 3D 대립(Opposition) 협응 및      │
│ (Sphere Grasp)   │ (직경 7.0cm 구 / 야구공 규격)│ Jeannerod MGA 조절/개구 결손 판별    │
├──────────────────┼──────────────────────────────┼──────────────────────────────────────┤
│ **Task 4**       │ Master-Slave 미러테라피      │ 양측성 훈련(BAT) 및 거울신경세포     │
│ (Mirror Therapy) │ (Bilateral Mirror Tracking)  │ 자극을 통한 즉각적 가동범위/경직 개선│
└──────────────────┴──────────────────────────────┴──────────────────────────────────────┘
```

### 2.1 과제별 임상적·생체역학적 선정 당위성

1. **Task 1 (맨손 1개: 최대 굴곡 및 신전)**:
   * **외력/보상 차단**: 물체에 손을 지탱하는 기계적 보상 작용을 원천 차단하고, 피질-척수로의 순수한 내인성 신경근 조절력을 측정합니다.
   * **손가락 독립 분리도 (Individuation)**: 뇌졸중 후 나타나는 집단 굴곡 연합 반응(Mass Synergy)을 손가락 관절 시계열 상호상관 행렬로 정량화합니다.
   * **무가림 캘리브레이션**: 물체 가림이 없는 상태에서 환자 고유의 최대 가동범위를 측정하여 Task 2, 3의 손끝 가림 보정 필터(Occlusion Hold) 기준치로 활용합니다.

2. **Task 2 (물체 1: 직경 5.0cm 원통 파지)**:
   * **임상 표준 규격 준용**: 국제 표준 척도인 **ARAT (Action Research Arm Test) Subtest 2 (Grip)**의 표준 원통형 블록(직경 5.0cm) 규격을 그대로 적용.
   * **파워 파지(Power Grasp) 역학**: 성인 손 평균 크기(17~19cm)에서 MCP 45°, PIP 70°, DIP 40°의 이상적 굴곡을 유도하여 음료수 캔, 컵 등 일상생활(ADL) 파지 기능을 대변합니다.

3. **Task 3 (물체 2: 직경 7.0cm 구형 파지)**:
   * **FMA-UE 공인 규격 준용**: **FMA-UE 수부 평가의 Spherical Grasp 검사 도구**(야구공/테니스공 직경 7.0cm) 표준 규격 적용.
   * **3D 엄지 대립(Opposition) 유도**: 평면 파지와 달리 엄지손가락이 손바닥 안쪽으로 35° 이상 회전 대립하고 제1배측골간근이 작용해야 파지가 성립됩니다.
   * **Jeannerod 개구 법칙 검증**: 물체 직경 7.0cm는 뇌졸중 환자의 파지 전 성형(Pre-shaping) 결손인 **MGA 과소(Hypometria) / 과대(Hypermetria)**가 가장 뚜렷하게 판별되는 임계 크기입니다.

4. **Task 4 (중재: Master-Slave 공압 미러테라피)**:
   * **치료와 진단의 폐루프 연동**: 건측 손의 움직임을 비전으로 70ms 이내 실시간 추종하여 환측 공압 글러브를 능동 가압(Grasp 보조)합니다.
   * **Pre vs Post 개선 즉각 실증**: 15분 미러 훈련 직전(Pre)과 직후(Post)의 $\Delta\text{TAM}$, $\Delta\text{SPARC}$를 동일 시스템에서 즉시 비교 검증합니다.

## 3. 표준 생체역학 지표 및 수학적 정식화 (Biomechanical Metrics)

본 연구는 신뢰할 수 없는 블랙박스 AI 점수에 의존하지 않고, 의학/생체역학계에서 수십 년간 검증된 **3대 골드 스탠다드 표준 지표**를 비접촉 환경에서 추출합니다.

### 3.1 총 능동 운동 범위 (TAM / TAROM, Total Active Motion)
미국수부외과학회(ASSH) 표준 지표로, 14개 손가락 관절의 능동 굴곡각에서 신전 결손을 집약한 전수부 가동성 종합 척도입니다:
$$\text{TAM} = \sum_{f \in \{\text{Thumb, Index, Middle, Ring, Pinky}\}} \left( \max_{t} \theta_f(t) - \min_{t} \theta_f(t) \right) \quad (^\circ)$$

### 3.2 정규화 최대 개구율 (MGA Ratio %, Maximum Grip Aperture)
Jeannerod(1984)의 파지 운동학 법칙을 준용하며, 거리와 피험자 체격 편차를 제거하기 위해 손바닥 기준 길이로 정규화합니다:
$$\text{MGA Ratio} = \max_{t \in [t_{\text{reach}}, t_{\text{grasp}}]} \left( \frac{\|P_{\text{Thumb\_TIP}}(t) - P_{\text{Index\_TIP}}(t)\|}{\|P_{\text{Middle\_MCP}} - P_{\text{Wrist}}\|} \right) \times 100 \quad (\%)$$

### 3.3 운동 매끄러움 지표: SPARC (Spectral Arc Length)
Balasubramanian et al. (IEEE TNSRE 2015)이 정립한 표준 운동 매끄러움 척도로, 푸리에 변환된 각속도 스펙트럼의 호 길이(Arc length)를 계산하여 경직과 다중 떨림(Submovements)을 정밀 정량화합니다:
$$\text{SPARC} \equiv -\int_0^{\omega_c} \sqrt{\left(\frac{1}{\omega_c}\right)^2 + \left(\frac{d\hat{V}(\omega)}{d\omega}\right)^2} d\omega$$
* $\omega_c$: 최대 진폭의 5%($\text{amp\_th}=0.05$) 이상인 유효 적응형 컷오프 주파수.
* 정상인(0에 수렴) 대비 뇌졸중 환자는 음수 절대값이 크게 증가하여 마비 중증도를 민감하게 반영.

### 3.4 양손 대칭도 지수 ($SI$) 및 제어 지연 시간 ($\tau_{\text{lag}}$)
$$SI = \left( 1 - \frac{\sum_{i=1}^5 |\Delta\theta_{i}^{\text{건측}} - \Delta\theta_{i}^{\text{환측}}|}{\sum_{i=1}^5 \Delta\theta_{i}^{\text{건측}}} \right) \times 100\%, \quad \tau_{\text{lag}} = \arg\max_\tau \int v_{\text{건측}}(t) v_{\text{환측}}(t + \tau) dt$$

## 4. 피험자 대조군 설계 및 임상 시험 프로토콜

```
┌───────────────────────────────────────┬───────────────────────────────────────┐
│ 정상 대조군 (Healthy Control, $N=15$) │ 뇌졸중 편마비 환자군 (Stroke, $N=15$) │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ • 만 20세 이상 성인 (남/여)           │ • 뇌경색/뇌출혈 편마비 진단 (발병 > 3개월)│
│ • 신경계/근골격계 상지 질환 병력 없음  │ • **FMA-UE 점수: 20 ~ 55점** (경도~중등도)│
│ • 비접촉 시스템 기기 신뢰도(Test-     │ • **Brunnstrom Hand: 3 ~ 5단계**      │
│   Retest) 및 표준 정상 운동학 데이터  │ • **MMSE(인지기능): 24점 이상** (지시 수행)│
└───────────────────────────────────────┴───────────────────────────────────────┘
```

### 4.1 제외 기준 (Exclusion Criteria)
1. 손가락 관절의 중증 구축(Contracture, 수동 가동범위 50% 이상 제한).
2. 심각한 시각 장애 또는 편측 무시(Hemispatial Neglect).
3. 수부 개방성 상처 또는 전염성 피부 질환.

### 4.2 단일 세션 임상 시험 절차 (Total: 약 30분)
1. **사전 평가 (Baseline, 5분)**:
   * 작업치료사/전문의에 의한 전통적 수기 FMA-UE 손 파트 및 전자 고니오미터 측정 (Ground Truth 확보).
2. **Pre-Intervention 비접촉 정량 평가 (5분)**:
   * 환자 모니터 앞 60cm 착석 ➡️ Task 1(맨손), Task 2(원통), Task 3(구) 각 3회 반복 수행.
   * 시스템 자동 연산: $\text{TAM}_{\text{pre}}$, $\text{MGA}_{\text{pre}}$, $\text{SPARC}_{\text{pre}}$ 자동 저장.
3. **Master-Slave 공압 미러테라피 중재 (Task 4, 15분)**:
   * 건측 손 동작을 비전으로 캡처하여 환측 공압 글러브 실시간 구동 (15분간 집중 미러 훈련).
4. **Post-Intervention 정량 재평가 (5분)**:
   * Task 1~3 재수행 ➡️ $\text{TAM}_{\text{post}}$, $\text{SPARC}_{\text{post}}$ 산출 ➡️ 중재 전후 회복도($\Delta$) 즉각 출력.

## 5. 하드웨어 구성 및 실시간 신호처리 최적화

```
[RealSense D435 / 웹캠] ──(16.6ms)──► [MediaPipe 3D 랜드마크] ──(15ms)──► [SVD 손바닥 정준화] ──(2ms)──►
                                                                                                  │
[총 지연: 69.6ms < 100ms] ◄──(35ms)── [공압 밸브/장갑 팽창] ◄──(1ms)── [시리얼 통신 115200] ◄─────┘
```

1. **손바닥 SVD 정준화 (SVD Hand Normalization)**:
   * 손바닥 6개 기준점의 공분산 행렬에 SVD를 적용하여 3차원 주축 기저를 형성.
   * 카메라를 비스듬히 보거나 손을 기울여도 **시점 및 거리 불변 내인성 해부학 각도 100% 보존**.
2. **One-Euro 필터**:
   * XY 평면 고속 추종($f_{c,\text{min}}=0.4\text{Hz}, \beta=0.08$) 및 Z축 깊이 노이즈 억제($f_{c,\text{min}}=0.15\text{Hz}, \beta=0.002$)로 지연 시간 5ms 미만 달성.
3. **Adaptive Occlusion Hold 필터**:
   * 물체 파지 시 손끝 가림 발생($\text{visibility} < 0.5$) 시 직전 유효 각도를 3초간 지수 보존($\alpha=0.98$)하여 데이터 튐 원천 차단.

## 6. 통계적 검증 계획 및 성공 기준

1. **계측 타당도 (Concurrent Validity)**:
   * 전자 고니오미터 vs 비접촉 시스템 간 급간내상관계수 **$ICC(2,1) \ge 0.85$**, Bland-Altman 95% 일치 한계 검증.
2. **임상 지표 상관성 (Clinical Correlation)**:
   * 비전 기반 SPARC 및 TAM 지표와 수기 FMA-UE 손 점수 간 피어슨 상관계수 **$r \ge 0.70$ ($p < 0.01$)** 확보.
3. **미러테라피 유효성 (Intervention Efficacy)**:
   * 중재 전후 지표 변화($\Delta\text{TAM} > 0, \Delta\text{SPARC} > 0$)에 대해 **대응표본 t-검정(Paired t-test, $p < 0.05$)** 유의성 입증.

## 7. 기대 효과 및 결론

1. **임상적 파급력**: 의사의 수기 평가 시간(40분)을 5분으로 단축하면서도, 0/1/2점 이산 점수를 넘어선 정밀 연속 시계열 생체역학 지표를 제공.
2. **보급형 경제성**: 수천만 원대 외골격 장비 대신 **일반 웹캠과 소프트 공압 장갑(수십만 원대)**으로 시스템을 구성하여 병원뿐 아니라 **가정용 원격 재활(Home-based Telerehabilitation)**으로의 확장성 확보.
3. **학술적 기여**: 분절되어 있던 비전 운동학 분석과 로봇 미러테라피를 단일 플랫폼으로 융합한 **완결된 폐루프 실증 연구의 표준 프로토콜 제시**.
