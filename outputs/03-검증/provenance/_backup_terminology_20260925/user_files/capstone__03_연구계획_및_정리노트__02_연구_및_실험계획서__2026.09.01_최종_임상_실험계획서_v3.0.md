## 1. 연구 목적 및 가설

### 1.1 연구 목적
1. **정량적 계측 타당도 검증**: 비접촉 광학식(MediaPipe + RealSense) 핸드 트래킹 기반 관절각 및 생체역학 지표(TAROM, MGA, SPARC)가 표준 수기 고니오미터 및 임상 평가(FMA-UE)와 높은 상관성(Concurrent Validity)을 가지는지 검증.
2. **Master-Slave 미러테라피 유효성 검증**: 건측 손의 동작을 실시간으로 추종하여 환측 공압 글러브를 능동 구동하는 미러테라피 프로토콜이 뇌졸중 편마비 환자의 수부 가동 범위 및 운동 매끄러움 회복에 미치는 즉각적/단기적 효과 평가.

### 1.2 연구 가설
- **가설 1**: SVD 손바닥 정규화 기반 내인성 관절각 측정값은 수기 고니오미터 측정값 대비 급간내상관계수(ICC) 0.85 이상의 높은 신뢰도를 나타낼 것이다.
- **가설 2**: 뇌졸중 환자의 파지 동작 시 SPARC(Spectral Arc Length) 지표는 FMA-UE 원위부(Distal) 점수와 유의한 양의 상관관계($r > 0.60, p < 0.05$)를 보일 것이다.
- **가설 3**: Master-Slave 미러테라피 훈련 후 환측 손의 TAROM 및 MGA가 통계적으로 유의하게 증가할 것이다.

## 2. 피험자 선정 및 제외 기준

### 2.1 대상자 모집군 (총 30명 목표)
1. **정상 대조군 (Healthy Control Group, $N=15$)**:
   - 만 20세 이상 성인 (남/여)
   - 신경계 및 근골격계 상지 질환 병력이 없는 자
2. **뇌졸중 편마비 환자군 (Stroke Patient Group, $N=15$)**:
   - 뇌경색 또는 뇌출혈로 인한 편마비 진단을 받은 자
   - Fugl-Meyer Assessment 상지 영역(FMA-UE) 점수 20~55점 (경도~중등도)
   - Brunnstrom Stage 3~5단계 (부분적 수부 파지 동작 가능)
   - 인지기능(MMSE) 24점 이상으로 지시 수행이 가능한 자

### 2.2 제외 기준
- 손가락 관절의 중증 구축(Contracture, 관절가동범위 50% 이상 제한) 환자
- 심한 시각 장애 또는 편측 무시(Hemispatial Neglect)로 화면 모니터링이 불가능한 자
- 손 부위에 개방성 상처나 피부 질환이 있는 자

## 3. 표준 실험 태스크 및 프로토콜 (4대 표준 Task)

실험은 조명이 균일한 실험실 환경에서 진행되며, 피험자는 모니터 앞 60cm 거리에 편안히 착석한 상태로 수행한다.

```
┌──────────────┬────────────────────────────────┬──────────────────────────┐
│ 태스크 구분   │ 동작 명칭 및 프로토콜           │ 주요 측정 임상 지표      │
├──────────────┼────────────────────────────────┼──────────────────────────┤
│ **Task 1**   │ 맨손 최대 쥐기 및 펴기         │ 5지 TAROM, 각 관절 ROM   │
│              │ (Free Hand Full Flexion/Ext)   │ (Thumb IP, Index/Mid PIP)│
├──────────────┼────────────────────────────────┼──────────────────────────┤
│ **Task 2**   │ 원통형 물체 파지               │ Grip Aperture (MGA %),   │
│              │ (Cylindrical Grasp: 캔/물병)   │ 운동 매끄러움 (SPARC)    │
├──────────────┼────────────────────────────────┼──────────────────────────┤
│ **Task 3**   │ 구형 물체 파지                 │ 정규화 MGA (%),          │
│              │ (Spherical Grasp: 야구공/탁구공)│ 손가락별 굴곡 협응도     │
├──────────────┼────────────────────────────────┼──────────────────────────┤
│ **Task 4**   │ Master-Slave 미러테라피         │ 건측-환측 대칭성 (%),     │
│              │ (Bilateral Mirror Tracking)    │ 공압글러브 보조 하 TAROM │
└──────────────┴────────────────────────────────┴──────────────────────────┘
```

### 3.1 세부 진행 순서 (Trial Protocol)
1. **사전 준비**: 피험자 기본 정보(이름, 나이, 성별, 환자 여부, FMA-UE 점수, Brunnstrom 단계, 마비측) 입력 후 세션 시작 (`Space`).
2. **동작 수행**:
   - 태스크 선택 후 준비 자세(손을 편 상태) 유지.
   - `Space` 키 입력과 동시에 3회 반복 파지 동작 수행 (동작당 3~5초 소요).
   - 파지 완료 후 `Space` 키로 즉시 저장. (0.4초 미만 오작동 자동 필터링).
3. **휴식 시간**: 태스크 간 2분간의 충분한 휴식을 제공하여 근피로도 발생 방지.

## 4. 정량 평가 지표 산출 공식

1. **총 능동 가동 범위 (TAROM, Total Active Range of Motion)**:
   $$\text{TAROM} = \sum_{f \in \{\text{Thumb, Index, Middle, Ring, Pinky}\}} (\max(\theta_f) - \min(\theta_f)) \quad (^\circ)$$

2. **정규화 최대 개구율 (MGA, Maximum Grip Aperture %)**:
   $$\text{MGA} = \max \left( \frac{\|P_{\text{Thumb\_TIP}} - P_{\text{Index\_TIP}}\|}{\|P_{\text{Middle\_MCP}} - P_{\text{Wrist}}\|} \right) \times 100 \quad (\%)$$

3. **운동 매끄러움 지표 (SPARC, Spectral Arc Length)**:
   $$\text{SPARC} = -\int_0^{\omega_c} \sqrt{\left(\frac{1}{\omega_c}\right)^2 + \left(\frac{d\hat{V}(f)}{df}\right)^2} df$$
   - $\hat{V}(f)$: 60Hz 리샘플링 속도 신호의 Zero-padded 정규화 주파수 스펙트럼
   - $\omega_c$: 최대 진폭의 5%($\text{amp\_th}=0.05$) 이상인 유효 적응형 컷오프 주파수

## 5. 데이터 관리 및 통계 분석 계획

### 5.1 데이터 수집 및 무결성 관리
- 각 Trial별 시계열 CSV 파일(`_timeseries.csv`)에 14개 관절각(Raw & Filtered) 및 **21개 3D 랜드마크 좌표(63열)** 자동 저장.
- 요약 데이터(`_Summary.csv`) 및 피험자 메타데이터(`subject_metadata.json`) 자동 통합 보관.

### 5.2 통계 분석 방법
1. **타당도 검증**: 전자 고니오미터 vs 비접촉 시스템 간 급간내상관계수(ICC(2,1)) 및 Bland-Altman 95% 일치 한계(Limits of Agreement) 산출.
2. **신뢰도 검증**: 검사-재검사(Test-Retest) 신뢰도 및 표준측정오차(SEM) 산출.
3. **임상적 유효성 검증**: 미러테라피 전후 환측 지표 비교를 위한 대응표본 t-검정(Paired t-test) 및 FMA 점수와의 피어슨 상관분석 ($p < 0.05$ 기준 유의성 판정).
