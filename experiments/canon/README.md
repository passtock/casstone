## 왜 만들었나

| 문제 | 확인된 사실 |
|---|---|
| **엄지 관절 정의 오류** | 계획서 §7.1은 `CMC–MCP–IP=(1,2,3)`, `MCP–IP–TIP=(2,3,4)`. 내 v15 코드와 **v14/29차 코드도** `(0,1,2)`·`(1,2,3)` 을 썼다 → **29차 F_sum14·TAM 계열 값도 정의가 틀렸다** |
| **분절 규칙의 지위** | 계획서 §8.2는 분절 불일치 비율(상한 30%)을 손 M1·M2 **게이트 조건**으로 두었다. 정지 기준선이 없으면 `segment_baseline_unavailable`로 무력화되고(파일럿 8/8), 손끝 한 점 오류는 "2개 이상 동시 위반" 조건에서 검출되지 않는다 |

## 오라클 결과

```
python experiments/canon/oracle.py     # PASS 35 / FAIL 0
```

주요 검사:
- 엄지 `(1,2,3)`·`(2,3,4)` 이고 `(0,1,2)` 를 쓰지 않는다
- 굴곡각 14개, 분절 15개가 계획서와 일치, D_TI_max는 엄지·검지 6분절
- **`decide_hand_gate` 소스에 `segment`/`SEG_`/`tol_seg` 문자열이 없다**(정적 검사)
- **★ 진단값이 상한(30%)을 초과해도 게이트는 통과**(합성 비율 0.425 → `pass`)
- 격하가 무력화가 아니다: 추적률 0.50 / 미검출 10×dt_ref / 유효 5프레임 / 손-일관성 30% → 모두 `hold`
- 손-일관성: 0→8 = 300 mm·10 mm 프레임은 무효

## 정정 — 내가 과장했던 것

내가 `v15` 보고서에서 "**새로 발견한** 구조적 사각지대"라고 쓴 내용(손끝 한 점은 "2개 이상" 조건에서 검출 불가)은 **계획서 §8.2 '알려진 사각지대'에 이미 명시**돼 있었다. 계획서는 그중 4·8·12를 손-일관성 검사로 보완하고, 16·20은 **어떤 게이트에도 들어가지 않음을 한계로 선언**했다. 나는 이미 알려진 한계를 새 발견으로 제시했다.

또한 **강체 검사에서 I3(전체 스케일)만 검출된 것**도 같은 이유다 — 계획서가 미리 적어 둔 사각지대의 재확인일 뿐이다.

## 주의

- 이 폴더의 코드는 **정의와 게이트 골격**만 담는다. 임상 검증된 임계값이 아니다(계획서 §8.2 첫 문장).

- 옛 정의를 쓴 스크립트(`failure_injection.py` 등 `experiments/v15/*`)는 **그대로 남겨 두었다.** 실행하면 틀린 엄지 정의를 쓰므로, 새 계산은 반드시 이 폴더의 `defs.py` 를 쓴다.
