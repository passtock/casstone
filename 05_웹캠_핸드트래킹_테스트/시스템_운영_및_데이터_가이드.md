# 🦾 공압장갑 Master-Slave 미러테라피 및 AI 손 기능 정량 평가 시스템 v3.0 운영 가이드

본 문서는 `app_gui.py` 시스템의 구동 방법, UI 기능, 단축키, 하드웨어(Intel RealSense) 연결 및 데이터 저장 구조를 설명하는 종합 운영 매뉴얼입니다.

---

## 1. 주요 기능 및 특징 (v3.0 Release)

1. **하이브리드 카메라 자동 전환**:
   - Intel RealSense RGB-D 카메라 자동 감지 및 1순위 연결 (`640×480 @ 30fps Color + Depth Z16 Align`)
   - RealSense 미연결 시 일반 웹캠(`Cam #0`)으로 자동 안전 Fallback
2. **SVD 다점 평면 피팅 기반 시점/거리 불변 관절각**:
   - 피험자가 카메라 전후(Z축)로 움직여도 왜곡 없는 순수 내인성 3D 굴곡각 산출
3. **표준 SPARC (Spectral Arc Length) 연산**:
   - *Balasubramanian et al. (2015)* 원본 알고리즘 적용 (가변 FPS 60Hz 리샘플링 + 적응형 5% 컷오프)
4. **환측(Affected Side) 자동 연동 및 데이터 무결성**:
   - 환자군 등록 시 지정된 환측 마비손 데이터를 자동으로 추출·분석·저장
5. **실시간 3D 스켈레톤 뷰어 & 2D 시계열 차트**:
   - 탭 전환(`QTabWidget`) 방식으로 60 FPS 고성능 렌더링 지원

## 2. GUI 화면 구성 및 조작법

### 2.1 단축키 (Hotkeys)
- **`Space`**: 
  - 세션 시작 전: 피험자 정보 입력 후 **세션 시작**
  - 세션 진행 중: **[파지 시작] ➡️ [파지 완료 및 자동 저장]** 원스톱 토글
- **`M`**: 화면 좌우 **미러링 모드 토글** (기본값: ON)

---

### 2.2 피험자 등록 패널 (좌측)
1. **피험자 기본 정보**:
   - 이름 (특수문자 자동 정제), 나이, 성별
   - 그룹 선택: `정상 대조군(Healthy)` vs `뇌졸중 환자군(Patient)`
2. **임상 재활 척도 (환자군 선택 시 활성화)**:
   - **FMA-UE 점수**: 상지 기능 평가 점수 (0 ~ 66점)
   - **Brunnstrom Stage**: 1단계(이완) ~ 6단계(정상)
   - **환측(Affected Side)**: `우측 (Right Hand)` 또는 `좌측 (Left Hand)`

---

### 2.3 실시간 모니터링 탭 (우측)
- **탭 0: 🌐 3D 손 스켈레톤 뷰어 (기본)**:
  - 21개 관절 노드, 5색 손가락 뼈대, 반투명 손바닥 메쉬(`Poly3DCollection`)
  - 마우스 드래그로 3D 회전 및 휠 줌 지원
  - 손이 화면 밖으로 나가면 잔상 없이 즉시 클리어
- **탭 1: 📈 굴곡각 시계열 차트 (2D)**:
  - 5개 손가락 대표 굴곡각 및 Trial 구간 하이라이트 실시간 표시

## 3. 데이터 저장 경로 및 파일 구조

세션을 시작하면 `05_웹캠_핸드트래킹_테스트/output/` 폴더 아래에 피험자 전용 폴더가 자동 생성됩니다.

```
📁 output/
 └── 📁 20260901_112030_환자_홍길동_65세_남성_FMA35_BRS4/
      ├── 📁 Task1_자유파지/
      │    ├── Task1_Trial_01_timeseries.csv   # 시계열 원본 (관절각 + 21개 3D 좌표 63열)
      │    ├── Task1_Trial_01_summary.json     # 회차 메타데이터 (MGA, TAROM, SPARC)
      │    ├── Task1_Trial_01_plot.png         # 각도 및 개구율 시각화 그래프
      │    └── Task1_Summary.csv               # Task 1 전체 회차 요약 테이블
      ├── 📁 Task2_원통형파지/
      ├── 📁 Task3_구형파지/
      ├── 📁 Task4_미러테라피/
      ├── Session_Overall_Summary.csv          # 세션 전체 요약 CSV (엑셀 한글 호환)
      └── subject_metadata.json                # 피험자 임상 정보 및 전체 결과 JSON
```
