# 손 재활 평가용 VLM에 비디오와 3차원 운동학 수치를 함께 입력하는 방법

**문헌 확인 시점:** 2026-09-21  
**대상:** 뇌졸중 후 손 동작 영상, 3차원 운동학, 건강 대조군 요약값을 이용한 임상 평가 연구  
**근거의 구분:** 아래의 `직접 근거`는 임상 동작을 VLM 계열 모델이 평가한 연구, `인접 근거`는 운동학을 VLM과 결합했으나 다른 동작 또는 학습 방식의 연구, `설계 제안`은 아직 해당 손 재활 과제에서 입증되지 않은 가설이다.

## 먼저 결론

1. **원수치와 범주 태그를 함께 입력하는 것이 가장 검증할 만한 설계**다. 측정값·단위·참조값을 보존하고, 참조 대비 차이와 방향성 태그를 **모델 밖에서 결정적으로 계산**한다. 모델에 직접 산술을 맡기거나 `정상보다 좁음` 같은 태그만 입력하는 전략의 우위는 손 재활 VLM 실험으로 확립되지 않았다. [xVal의 수치 토큰 연구](https://arxiv.org/abs/2310.02989), [MICCAI 2024 보행 VLM](https://arxiv.org/html/2403.13756v2).
2. **영상 위 텍스트 수치가 원수치 전달의 주 경로가 되어서는 안 된다.** 깨끗한 원본 프레임을 유지하고, 필요하면 별도의 복제 프레임에 손가락 끝·물체 윤곽·경로만 얇게 표시한다. 시각적 표식 연구는 위치 지시에는 도움이 되지만 임상 미세접촉·mm 판정의 향상을 입증하지 않았다. [SoM](https://arxiv.org/abs/2310.11441), [ViP-LLaVA](https://arxiv.org/abs/2312.00784).
3. **‘비디오+독립 센서 수치를 동결된 대화형 VLM의 추론 입력에 넣으면 뇌졸중 손 점수가 유의하게 오른다’는 직접 선행 근거는 확인되지 않는다.** 가까운 보행 연구는 수치를 **학습 중 표현 정렬에 사용하고 추론 시 영상만 입력**하거나, **영상으로 추정한 관절각을 토큰으로 바꾸고 추가 모듈을 학습**했다. 따라서 현재 계획의 A1–A4 비교가 필요한 이유가 분명하다. [MICCAI 2024](https://arxiv.org/html/2403.13756v2), [BioGait-VLM 2026 사전공개 논문](https://arxiv.org/html/2603.08564).

## 1. Float, 범주 태그, 이중 표현의 비교

| 입력 방식 | 장점 | 중요한 오류 | 권장 역할 |
| --- | --- | --- | --- |
| `최대 파지 간격 54.2 mm`처럼 원수치만 | 오차 크기 보존, 추후 재분석·검산 가능 | 기준값·동작 종류·단위가 빠지면 해석 불가; VLM의 소수 비교·산술과 유효숫자 처리에 의존 | **원자료의 추적 가능한 표현** |
| `건강 대조군 Q1보다 작음`처럼 태그만 | 방향성 해석이 쉽고 모델의 직접 계산을 줄임 | 1 mm 차이와 20 mm 차이를 같은 범주로 만듦; 경계 부근에서 태그가 뒤집힘; 잘못된 기준을 감춤 | **사전에 계산한 보조 해석** |
| `원수치 + 참조 요약 + 계산된 차이 + 태그 + 신뢰도` | 크기와 방향성을 함께 전달하고 사후 감사 가능 | 정보가 많아질 수 있어 변수 수를 미리 제한해야 함 | **주 가설로 권장; 실제 우위는 소거실험으로 검증** |

일반 LLM의 숫자 인코딩은 보통 숫자 간의 연속적인 거리 관계를 그대로 보존하지 않는다. [xVal](https://arxiv.org/abs/2310.02989)은 이 문제를 겨냥하여 별도 수치 임베딩을 학습한다. [Wang 등, MICCAI 2024](https://arxiv.org/html/2403.13756v2)도 단순히 `54.2`라는 문자열을 CLIP에 입력한 것이 아니라, **수치에 전용 임베딩 기저를 곱한 표현**을 만들어 건강인 평균 기준으로 정규화했다. 이것은 일반 Qwen/LLaVA에 float를 텍스트로 적으면 효과가 같다는 근거가 아니다.

### 재현 가능한 입력 예시

다음은 **설명용 가상 수치**다. 참고 통계는 동일 과제·물체 규격·계산 정의로 얻은 독립 건강인 데이터에서 계산해야 한다.

```json
{
  "task": "cylindrical_grasp",
  "hand": "paretic",
  "phase": "formation",
  "measurement": {
    "id": "F1_maximum_aperture",
    "value": 54.2,
    "unit": "mm",
    "definition": "thumb_index_tip_3d_distance_max",
    "reference": {
      "population": "healthy_same_task_and_object",
      "n": 15,
      "median": 67.4,
      "q1": 61.0,
      "q3": 72.8
    },
    "derived": {
      "delta_from_median_mm": -13.2,
      "ratio_to_median": 0.804,
      "band": "below_reference_q1"
    },
    "validity": "valid",
    "quality": {
      "tip_visibility_fraction": 0.93,
      "valid_depth_fraction": 0.89
    }
  }
}
```

`below_reference_q1`은 **이 소규모 표본의 제1사분위수보다 낮다는 기술적 표현**일 뿐, 곧바로 질환·병리·임상 실패를 뜻하지 않는다. 건강인 **15명**의 Q1/Q3는 기술 통계로 사용하고, 해당 표본만으로 안정적인 개인별 백분위수나 의학적 ‘정상 범위’를 확정하지 않는 편이 타당하다. 필요한 경우 대조군의 표본추출 불확실성을 부트스트랩으로 별도 보고한다.

실측 오차나 반복 측정 변동보다 작은 소수 자릿수는 빼고, 부정확한 좌표는 `"value": null`, `"reason": "occluded_fingertip"`처럼 기록한다. 결측을 `0`으로 채우거나 가려진 마디의 각도를 관측된 것으로 서술하면 설명이 오히려 더 그럴듯하게 틀릴 수 있다. 특히 거리·관절각은 측정 정의, 좌표계, 단위, 영상-깊이 동기화, 추적 품질을 고정해야 비교 가능하다.

**프롬프트의 역할 분담:** 전처리 코드가 mm 환산·요약·차이·태그를 계산하고, VLM은 주어진 수치와 영상이 **서로 부합하는지**, 어느 phase의 어떤 **관측 가능 단서**가 판정 근거인지 설명한다. 출력에는 인용한 `measurement.id`와 `frame_id`를 요구한다. 원수치와 태그가 충돌하면 강제로 결론을 내게 하기보다 `input_conflict`를 반환하도록 한다. 이는 안전한 구현 제안이지 그 자체로 환각 방지 효과가 임상시험에서 확증된 결과는 아니다.

여기서 [MICCAI 2024](https://arxiv.org/html/2403.13756v2)의 *visual prompt*는 영상에 선을 그린 표시가 아니라 **CLIP 내부에 학습 가능한 시각 토큰을 추가하는 방법**이다. 두 용어를 같은 선행기술로 인용해서는 안 된다.

**실험 권장안:** 동일한 formation/hold/release 프레임에 대해 `깨끗한 RGB`와 `얇은 표식이 있는 RGB 복제본`을 비교한다. 환측 손가락 끝·물체·3차원 파지 경로의 **2D 투영**과 낮은 추적 신뢰도를 표시하되, 0/1/2/3 등 **정답 점수**를 영상에 쓰지 않는다. 숫자는 별도 구조화 텍스트로 준다. 오버레이가 유일한 입력이면 선이 손가락 끝과 실제 접촉면을 가려 성능이 떨어질 수도 있다. 깊이가 다른 두 표면의 2D 투영이 겹친다는 사실만으로 접촉을 확정할 수 없다. **환각 감소·점수 상승은 해당 손 과제에서 원본 대 오버레이 소거실험으로 확인해야 한다.**

**학술적 해석:** MICCAI 연구에서 `67.76−64.78=2.98%p`는 *수치와 임상 지식 등을 포함한 학습 방식 전체*의 차이이며, 숫자만 추가한 실험은 보행 점수에서 오히려 **0.34%p 낮았다**. BioGait의 `68.1−64.3=3.8%p`는 다른 구성 요소를 고정하고 **영상에서 추정한 3D 역학 가지**를 추가한 차이지만, 별도 센서 또는 무학습 추론 프롬프트의 효과가 아니다. BioCoach는 **운동 조언 문장의 질**을 높인 인접 근거이며, 사람 환자의 기능 점수 정확도를 증명하지 않는다. 이 범위에서 독립 센서 수치의 추가가 동결된 Qwen의 뇌졸중 손 평가를 **통계적으로 유의하게 개선한다는 주장은 현재 할 수 없다.**

`npj Digital Medicine에 동일한 입력·대상·VLM 구조의 검증 논문이 있다`는 식의 저널명 근거 없는 주장은 피하는 편이 낫다. 선행 연구를 인용할 때는 **대상 질환, 센서가 독립 계측인지 영상에서 추정했는지, 추론 단계에 수치가 있는지, 모델/어댑터 학습 여부, 환자별 독립 검증**을 표에 명시한다.

## 4. 현재 손 연구의 실행 가능한 대조실험

| 조건 | 입력 | 검증할 질문 |
| --- | --- | --- |
| A1 | 동일 환측 손 동작의 원본 영상/고정된 14프레임 | 비디오만의 점수·설명 |
| A2 | A1 영상 + 운동학 측정/품질 정보 | **운동학 추가 가치**: A2−A1 |
| A3 | A2 + 동일 과제의 건강 대조군 median, Q1, Q3 및 사전 계산한 차이·태그 | **참조 비교 추가 가치**: A3−A2; 전체 주효과 A3−A1 |
| A4 | A3의 수치·참조값만, 영상은 제외 | **영상 자체의 기여**: A3−A4 |
| A0 | 동일 수치 기반의 작은 비생성형 모델 | VLM 도입의 성능·복잡도 대조 |

위 표는 연구 계획에 맞춰 정리한 **실험 설계안**이다. 과제와 프레임 추출 규칙, 질문, 출력 JSON 스키마, 모델 버전, 디코딩 설정을 조건 간 동일하게 고정한다. 여러 반복을 같은 사람에게서 얻었다면 분할·신뢰구간 계산의 독립 단위는 **사람**이다. 건강인 대조 통계는 평가 대상 환자의 점수나 평가 반복을 사용해 조정하지 않는다.

### 입력 표현과 오버레이의 별도 소거실험

| 하위조건 | A3 안에서 바꿀 한 가지 |
| --- | --- |
| D-num | 측정 float·단위·참조값만 |
| D-tag | 사전 산출한 `below_Q1 / Q1_to_Q3 / above_Q3` 등 태그만 |
| D-both | 원수치+사전 계산된 차이+태그+신뢰도 |
| D-mark | D-both를 유지하며 **표식만 추가**; 표식의 효과를 분리 |

**주요 성능:** 환자 단위로 집계한 A3−A1의 ordinal MAE와 95% 신뢰구간. 보조로 정확도, 가중 κ, A2−A1·A3−A2·A3−A4·A3−A0, 전문가 간 합치도를 보고한다. 설명은 단순한 유창함 대신 (1) **보이는 영상 근거/프레임 제시**, (2) **존재하는 측정값만 인용**, (3) **입력과 다른 숫자 생성 비율**, (4) **가림·결측 시 유보**, (5) **반복 실행의 점수/설명 일관성**으로 평가한다. 잘못된 측정값을 의도적으로 섞거나 숫자 태그를 서로 뒤집는 반사실 실험은 모델이 어떤 입력에 과도하게 매달리는지 드러낼 수 있지만, 실제 점수 분석과 구분해 실시한다.

**레이블 명칭 주의:** 정식 ARAT 과제·절차·0–3점 규칙을 그대로 적용하지 않았다면, 변형된 손 과제의 0–2/0–3점은 `ARAT 점수`로 부르지 않고 전문가가 정의한 별도의 **과제별 수행 질 점수**로 표기해야 한다. ARAT와의 상관은 별도 결과로 제시한다. [2026년 ARAT 연구의 과제/단계별 계층 평가 사례](https://arxiv.org/html/2606.24960v1)도 점수 목표의 정확한 정의가 중요함을 보여준다.

**연구 문장 제안:** “본 연구는 동일한 뇌졸중 환자의 손 과제 영상에 측정된 3차원 운동학 특징, 과제별 건강 대조군 참조값, 측정 품질 정보를 단계적으로 추가하여, 동결된 VLM의 환자 단위 평가 오차와 근거의 충실도가 개선되는지를 검증한다. 숫자 전달 형식과 영상 표식의 효과는 별도의 동일 사례 소거실험으로 분리한다.”
