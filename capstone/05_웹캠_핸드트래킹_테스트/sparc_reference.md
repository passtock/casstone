# 품질 진단 및 SPARC 추가 구현 근거

2026-09-08. 원본 각도·좌표·좌우 라벨을 변경하지 않는 추가 분석이다. 기존 지표와 별도 필드로 보존한다.

## 1차 출처
- Balasubramanian et al., *On the analysis of movement smoothness*, JNER 12, 112 (2015). DOI: https://doi.org/10.1186/s12984-015-0090-9 . 출판사 원문: https://link.springer.com/article/10.1186/s12984-015-0090-9 . 움직임 분할이 분석 결과에 영향을 준다는 점을 명시한다.
- 저자 공개 참조: https://github.com/siva82kb/SPARC/blob/master/scripts/smoothness.py (2026-09-08 열람). `sparc`의 주파수 상한 10 Hz, 정규화 진폭 0.05로 마지막 유효 주파수를 선택하는 적응 절단, 패딩 수준 4 및 정규화 스펙트럼 호 길이 정의를 확인했다. 함수 문서의 가우시안 예제 결과 -1.41403을 회귀 검사의 기준으로 사용한다. 참조 코드를 복사하지 않고 수식을 구현했다.

## 구현 계약과 제한
- `sparc_segment`: 초 단위 시각과 동일 단위의 비음수 속력. 한 동작의 연속 구간만 전달한다. 구간 분할, 각도/위치 미분은 호출자 책임. MP와 RS, 원본과 필터 입력을 섞지 않는다.
- 원본 개수와 양끝 시각을 유지하는 선형 균등 재표본화 뒤 FFT. 원본 배열을 덮어쓰지 않는다. 양의 속력의 DC가 최대이므로 0 Hz부터 적응 절단까지 적분한다. 나이퀴스트를 초과하는 주파수는 사용하지 않는다.
- 10표본 미만, 0.5초 미만, 0.25초 초과 공백, 결측/비유한 값, 중복/역순 시각, 음수 속력, 전부 0인 속력은 값 대신 `None`과 사유를 반환한다. 표본·시간·공백 기준은 공학적 기본값이며 임상 검증 기준이 아니다.
- 구간을 자동 분할해 최대/평균 SPARC를 채택하지 않는다. 전체 회차가 단일 동작인지 확인 전에는 예비 분석으로만 사용한다. 음수 값의 범위를 임의로 제한하지 않는다.
- `assess_hand_identity`: 비미러링 정규화 영상 손목 XY의 직접 대응/교차 대응 거리 차이만 사용. 두손이 모두 연속 관측된 경우에만 의심 flag를 만든다. 교차하는 실제 움직임과 라벨 교환을 확정 구별하지 못한다. 0.03 모호성 차이 및 0.75초 공백 한계는 조정 가능한 진단 기본값이다. 좌우를 교환하거나 좌표를 보정하지 않는다.
- `gap_plot_arrays`: 시간 공백에 NaN 구분자만 추가. 결측값을 0으로 바꾸거나 선형으로 메우지 않는다.

## 검증 상태
- NumPy 의존. 추가 패키지 없음. 난수·학습·실제 입력 데이터 없음.
- 합성 회귀 검사는 작성만 했으며 실행하지 않았다. 카메라·GUI·실제 측정도 실행하지 않았다. AST 문법 확인은 총괄 실행 기록에 별도 기재한다.
- 해시와 명령, 로그 위치는 총괄의 이번 변경 실행 기록에 통합한다. 연구설계 및 원본·이전 결과는 변경하지 않는다.
