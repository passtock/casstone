# 실험계획서 최종본

## 단일 RGB-D 파지 운동학의 측정 오류 → VLM 채점 전파와 품질 기반 입력 선택, 그리고 정상 파지 서브타이핑

**문서 지위:** **정본(유일본).** 이 문서가 연구 질문·배경·선행연구·설계·절차·분석·한계를 모두 담는다. 이전 판본(연구계획서 v6.x, 실행 프로토콜 v6, 설계이력, 초안·계획 스크래치)은 **삭제**되었다(§16 삭제 기록).
**작성:** 2026-09-30 · **계보:** v5 실행계획 → v6.0~v6.4(2026-09-22~28) → **v7 최종본(본 문서, 2026-09-30)**
**표기:** `A`=1차 원문 직접 확인 · `B`=2차 자료(초록·공식문서) · `C`=자체 계산·합성(재현 가능) · `D`=미검증 가정
**용어:** `비장애인`=건강 대조군 · `장애인`=뇌졸중 후 상지 기능장애 연구참여자(행정적 장애등록 여부와 무관). VLM 프롬프트에서는 "기능 저하"를 쓴다.
**동결 절차:** 최종 편집 후 `sha256sum` → 해시·날짜 기록.
`해시: ______________  날짜: ________`

> 🔴 **정확성 선언 (먼저 읽을 것).** 본 문서의 모든 수치는 출처 등급과 함께 기록했다. **본 ARAT 2과제 프로토콜의 실증 검증은 0건**이다 — **기존 기술 파일럿은 존재한다**(비장애인 2명·18시행, 실제 RGB 프레임; §15.1). 설계·코드 검증은 **문헌 원문 + 자체 합성 오라클**이다(§15). 미해결 블로커 3건(D-16 원시 depth 미저장, D-17 A1 교란, D-18 보조 모델 미확정)이 §15에 명시되어 있고, **이들이 해소되기 전에는 데이터 수집을 시작하지 않는다.**

## 1. 연구 배경 — 왜 이 연구인가

### 1.1 임상 척도의 한계(문제의 출발점)

| 사실 | 수치 | 출처 |
| --- | --- | --- |
| ARAT는 바닥·천장 효과를 보인다 | 발병 3일째 바닥 **38%**, 4주째 천장 **21.3%**, 180일째 천장 22.6% | Kristersson 2019 (N=117), PMID 30767025 |
| FMA-UE도 천장 효과 | 만점 **21.7%** | Kristersson 2019 |
| 평가자 간 갈림이 실재 | 항목 일치 >90%이나 **33항목 중 4개**가 갈림 | Hernández 2019, PMID 31448807 |
| "거의 정상" 경계가 흐릿 | 만성 고기능 'notable vs full' **특이도 0.55** | Valladares 2024, PMID 39224885 |
| 프로토콜이 통일되지 않음 | 6개 FMA-UE 프로토콜 불일치(예: 손목 돌리기 시 팔꿈치 0° vs 90°) | Fasoli 2025(구 표기 'Pohl 2024/25'), PMID 39461495 |

> **주의:** ①은 "우리가 새 점수를 만든다"는 뜻이 **아니다.** 우리는 **치료사 점수를 정답으로 쓴다.** ①은 **결과 해석의 위협 + 설계 제약**이다: (a) 라벨이 흐릿하면 "모델이 틀렸다"와 "라벨이 흐릿했다"를 구분할 수 없다 → **PR-1은 두 조건에 동일한 평가 기준(같은 라벨)을 적용**하므로 조건 간 비교에서 라벨의 체계적 차이가 줄어든다. 단 **같은 라벨을 쓴다고 라벨 오류가 MAE 비교에서 자동 상쇄되지는 않는다** → **평가자별(현장 vs 눈가림 영상) 분석**으로 결과 민감도를 확인한다. (b) 가장 흐릿한 경계가 1–2 구간(특이도 0.55) → **모집 분포 목표**(§6.1)의 근거. (c) 갈림이 실재 → **평가자 2인** 운영의 근거.

### 1.2 점수는 맞아도 수치는 틀릴 수 있다

**Li 2022**(N=20, RealSense vs Vicon, PMID 36291314): 손목 위치 **평균 96 mm 오차**인데 치료사 점수와 **r=0.981**.
→ **임상 점수가 맞았다는 것이 측정 수치가 맞았다는 뜻이 아니다.** 이것이 이 연구의 출발 명제다.

### 1.3 VLM 단독으로는 채점이 안 된다

**Li 2026**(비장애인 20 + 뇌졸중 51, PLOS Digit Health 5(7):e0001506, PMID 42406872): 예측 FMA가 **중증도 무관하게 평탄(flatlining)**, "무조건 1점" 기준선과 유사, **0점 장애인에게 환각**. 활동 인식은 87.2%/73.5%로 되지만 **항목 점수는 평탄**하다.

### 1.4 그래서 남은 빈칸

Li 2026은 **영상만** 줬다. 즉 문헌이 답하지 않은 것은:

1. **수치를 주면 나빠지는가?** (Li 2026은 미측정 — **PR-1**)
2. **품질로 골라 주면 나아지는가, 그 대가가 과잉 보류인가?** (**PR-2·PR-3**) — 위험한 지표를 걸러 내는 **개입의 인과 효과**는 아직 측정된 적이 없다.
   - 근거: Tang 2025(arXiv:2505.18412) — 예시 3개가 최적, **4개에서 0.42로 붕괴** → 정보를 더 주면 망가질 수 있다.
   - 근거: "Selective Prediction"(ACL 2024, arXiv:2402.15610) — **과잉 보류(over-abstention)가 명명된 실패 모드**인데, **임상 순서형 채점에서 비용 곡선은 측정된 적 없다.**

→ **주장은 "우리가 처음 제안"이 아니라 "우리가 처음 측정"으로 고정한다.**

**동시에 이미 선행된 것(재주장 금지):** ARAT 손 과제 운동학 측정·비장애인 비교(**Padilla-Magaña 2022**, §2.5), JSON·특징 주입(Tang 2025, Xing 2025), 불확실성·보류(xAARA), 운동학>순서형 점수(Unger 2026), 영상+수치 결합(UbiPhysio, BiomechGPT), 정상 파지 시너지·군집화(§2.6 전면).

**(3) 이 축의 3대 결론**

1. **"차원은 고정된 진리가 아니다."** 보고된 성분 수가 **2(Santello/Mason/Romero) → 3(Pratap) → 4(Gracia-Ibáñez·뇌졸중 van Kordelaar) → 5(Alt Murphy) → 12(Jarque-Bou)** 로 분산한다.
   → **"6차원 GMM"은 문헌이 검증한 값이 아니다.** 차원·K는 **데이터로 결정**해야 한다(BIC·silhouette·bootstrap stability + 분산 80% 기준 병기).
2. **정상 참조는 (a) 공통 core + (b) 개인 조합의 2층 구조**여야 한다(Gracia-Ibáñez). **개인차가 지배적**이므로(Herbst) **단일 평균 비교는 부적절**하다.
3. **특징 선택이 결론을 좌우한다**(Herbst: ~45% 변동) → **특징 사전등록 + 민감도 분석 필수**. **엄지–검지(대립·간격) 계열이 최우선 후보**다(Herbst 최다 기여, Jarque-Bou 시너지#3, Padilla-Magaña의 MCP/PIP 보상).
4. **문헌상 공백:** 정상군은 **비지도 서브타이핑**을 하지만, 뇌졸중군은 **분류·계층화**에 머문다. **뇌졸중 파지 운동학을 비지도로 서브타이핑한 연구는 확인되지 않았다.** (→ §12 후속 과제의 근거)

**⚠️ 비접촉 RGB-D의 간극:** 위 강한 결과는 대부분 **접촉식 장비**(CyberGlove II, Polhemus, Vicon/mocap)에서 **관절각을 직접 측정**해 얻었다. 우리는 **영상에서 추정**해야 하고, 파지 순간이 가장 가린다(§2.7).

## 3. 연구 질문·가설·주 결과

### 3.1 한 문장 질문
> 단일 RGB-D가 손과 물체의 가림 속에서 만든 수치를 **VLM이 얼마나 잘못 신뢰하는가**, 그리고 **측정 품질이 확인된 수치만 주면** 그 잘못된 신뢰가 줄어드는가?

### 3.2 가설 (방향 사전 등록)

| # | 가설 | 지지 관측 | 반증 관측 | 사전 근거 |
| --- | --- | --- | --- | --- |
| **H0** | ⭐수치를 주면 채점이 변한다(양방향) | `MAE(A2) ≠ MAE(A1)` (양수=주입이 해로움) | A2≈A1(수치를 안 읽음) | Tang 2025 붕괴; Li 2026은 영상만 줬으므로 **미측정** |
| **H1** | 품질 게이팅이 채점 오차를 줄인다 | `MAE(A3) < MAE(A2)` | A3≈A2 | 정보량·정보 품질이 성능을 바꾼다 |
| **H2** | 품질 규칙이 무작위 제거보다 낫다 | `MAE(A3) < MAE(R)` | A3≈R | "덜 봐서"와 "나쁜 걸 안 봐서"를 분리 |
| **H3** | 게이팅 이득은 보류율과 함께 움직인다 | (보류율,MAE) Pareto에서 이득 구간이 좁음 | 보류율 무관 | arXiv:2402.15610 과잉 보류 |
| **H4** | 영상은 수치와 다른 정보를 준다 | A3 < A4 | A4≈A3 | Li 2026 활동인식 87.2%/73.5% |
| **H5** | *(기전·**탐색적**)* 수치 오류가 커지면 채점 오차도 커진다 | bias_3u 주입 시 MAE↑ | 오염에 둔감 | Li 2026이 "VLM은 수치를 못 읽는다"를 이미 보임 → 재확인 위험 |

### 3.3 주 결과 (확증적, **Holm k=3**)

| # | 정의 | 왜 주 결과인가 |
| --- | --- | --- |
| **PR-1** | `I_i = MAE_i(A2) − MAE_i(A1)` — **수치 주입 효과**. **양수=주입이 해로움** | Li 2026은 영상만 줬으므로 **미측정**. 임상 배포에서 가장 먼저 알아야 할 위험 |
| **PR-2** | `G_i = MAE_i(A2) − MAE_i(A3)` — **게이팅 효과** | **같은 영상·같은 라벨**에서 수치 집합만 바꿈 → 라벨 변동 상쇄, **개입의 인과 효과** |
| **PR-3** | `E_i = MAE_i(R) − MAE_i(A3)` — **게이팅의 고유 가치** | A3는 A2보다 정보가 적음 → 정보량 교란을 R로 통제 |

**주 분석 대상(고정):** **T2(ARAT 12번)만** — T1은 2차·탐색적이며 두 과제를 풀링하지 않는다(§4). **주 검정법:** 양측 Wilcoxon signed-rank(Holm k=3), paired t는 민감도. **주 기준 평가자:** 현장 치료사(독립 영상 평가자는 민감도).

**1급 기술 결과(검정 아님, 반드시 보고):** 보류율(A3) · (보류율,MAE) Pareto(Q1 sweep) · 보조 모델 부호 일치.
**탐색적으로 강등(보정 없이 CI·효과크기만):** `A3−A4`, A0/A0-time, 프레임 밀도, 큰 오차(≥2점) 비율, bias_3u 기전(H5), 설명 평가.

## 4. 왜 이 태스크인가 (ARAT 3번·12번)

| 결정 | 값 | 근거 |
| --- | --- | --- |
| **과제 2개** | ARAT 3번 + 12번 | Unger 2026: pick-and-place 계열 **AUC 0.96→>0.99**로 가장 잘 갈림. ⚠️ **단 그 판별은 "0/1점(수행 실패) vs 2/3점(완수)" 구간**이며, **2점 vs 3점 구간은 AUC 0.70–0.84로 훨씬 낮다**(Unger Tier 2) |
| **숫돌 측면집기 제외** | 제외 | 엄지–검지 **끝 거리**와 연결이 약함 → **M1(K1_mp)과 무관**. ⚠️ **16활동→2항목 축소 이유를 논문에 설명할 의무**(Padilla-Magaña가 16활동을 다룸) |
| **T1=참고 / T2=주 결과** | 3번=참고, 12번=주 결과. **주 분석은 T2만이며 두 과제를 풀링하지 않는다**(T1은 2차·탐색적) | 3번은 "thumb and fingers in opposition이면 어떤 파지든 허용" → 손가락 쌍 미강제. 12번은 **엄지+검지 패드 맞섬 강제**(Yozbatiran Table A3) → **M1(K1_mp: 엄지–검지 거리)과 직접 연결** |
| **물성 정본** | 5 cm 블록 **55 g** → 선반 **37 cm**; 구슬 **⌀1.6 cm, 5.4 g** | **Yozbatiran 2008 Table A2** 채택(DOI 10.1177/1545968307305353). ⚠️ **Lyle 원형 채점지(ksu ARAT form)는 구슬을 1.5 cm로 기재** → **출처 간 불일치**이므로 "오류 정정"으로 단정하지 않는다. **실물 구슬을 캘리퍼로 측정해 실제 값을 논문에 명시**(D-19) |
| **3점 기준** | 5초 이내 정상 수행; 2=완료했으나 5–60초/큰 어려움; 1=60초 내 부분; 0=60초 내 불가 | Yozbatiran 2008 |
| **측정 설계 정합성** | 12번이 **엄지–검지 파지**를 강제하므로 우리의 **M1(K1_mp)** 과 **엄지–검지 대립** 가설(§2.6)이 과제 수준에서 정렬됨 | 우리 설계 |

**왜 "2개 과제"가 방어 가능한가:** ① 두 과제는 **손가락 구속이 다르다**(T1 자유 vs T2 강제) → M1이 **과제에 따라 다르게** 유효함을 보일 수 있다. ② 반복 시행과 **오류 전파 실험**에 집중하기 위한 축소이며, 이는 Padilla-Magaña(16활동)와 **경쟁이 아니라 상보**다: 그들은 **어떤 손가락 관절이 다른가**를, 우리는 **측정 오류가 채점에 어떻게 전파되는가**를 본다. ③ 축소 사유를 논문에 명시할 의무를 §13 체크리스트에 넣는다.

### 6.2 과제·물성·환경

| | ARAT | 대상 | 배치 | 3점 기준 |
| --- | --- | --- | --- | --- |
| **T1** | 3번 | 5 cm 목재 블록 **55 g** | 테이블 → **선반 37 cm 위** | 5초 이내 정상 수행 |

환경: 테이블 높이 **75 cm**(76×49), 의자 좌면 **46 cm**(팔걸이 없음, 몸통 등받이 접촉), 선반 테이블 면에서 **37 cm**·근위연에서 **20±5 cm**, 물체는 정중시상면과 액와선의 중간.
**채점 규칙(Yozbatiran 2008 원문 기준 — 최선 수행 원칙):**
- **최선 수행:** 점수는 **최선 수행**으로 매긴다. **물체를 떨어뜨린 뒤 다시 집어 수행해도 감점하지 않는다** (원문: “The score is based on the best performance. A subject is not penalized if a testing object is dropped and relifted.”).
- **낙하 구분:** (a) 낙하 후 **60초 내 다시 집어 완료** → 완료로 인정(품질·시간에 따라 2점 또는 3점, 낙하 자체는 감점 아님). (b) 60초 내 **다시 집지 못해 미완** → **부분 수행(1점)**. (c) **놓기 실패**(목표 뚜껑에 해제 못 함) 또는 **해제 시도 중 물체가 떨어짐** → **2점**.
- **성공 후 이탈:** 과제를 **성공적으로 마친 뒤** 물체가 선반/뚜껑에서 **튕겨나가거나 떨어지면 감점 없음**.
- **점수 정의:** 3=5초 이내 정상(정상 손·팔 움직임+자세; T2는 **패드** 사용) / 2=완료했으나 5–60초 또는 큰 어려움(잘못된 파지·해제 실패·T2 패드 미사용) / 1=60초 내 부분 수행(들어올렸으나 **목표 높이 미달** 등) / 0=60초 내 어떤 부분도 못함(**T2는 잘못된 손가락 맞섬이면 0점**).
- 1점은 **손으로 들어올린 경우**에만 준다(손등으로 밀기 등은 부분 수행이 아님). 각 항목 **60초 제한, 한 손만**, 소척도당 비환측 먼저, 손·팔 움직임 성분은 **Table A3** 기준.
⚠️ 두 항목 합계(0–6점)를 임상 점수로 쓰지 않는다. ⚠️ T2의 "지정 손가락·패드 사용"은 **표준 채점 기준**이다.

#### 6.3.1 🔵 시행 경계 규칙 (**확정**, 2026-09-30 · F3b)

> **목적:** 시행 경계를 **사람의 재량이 아니라 기계적 규칙**으로 만들어(자동 분할 가능·재현 가능·검증 가능) D-23을 해결한다.

**시행마다 아래 순서를 그대로 반복한다 (연습 포함):**

```
[정지 2초] → 큐(LED/비프 또는 구두 “시작”) → 동작(≤60초) → [정지 2초]
```

| 항목 | 확정 규칙 |
| --- | --- |
| **앞 여유** | 큐 직전 **정지 2초**(손을 시작 위치에 둔 상태로 가만히) |
| **큐** | ① 앱에 “시작” 키를 두면 **키 누름 시각을 로그에 기록**(`cue_t`), ② 동시에 **LED/비프를 영상에 남긴다**(독립 확인용) |
| **동작** | 지시문 수행. **ARAT 60초 상한** |
| **뒤 여유** | 물체를 놓은 뒤 **정지 2초**를 유지한 뒤 종료 |
| **시행 시작 정의(사전등록)** | **`cue_t`**(사람이 고르지 않음) |
| **시행 종료 정의(사전등록)** | **물체 놓기(release) 확인 시점**, 없으면 `cue_t + 60초` 상한 |
| **원시 보존 구간** | `cue_t − 1.0초 ~ 종료 + 1.0초` 를 **L0/L1에 전부 보존**(분석 구간 밖도 삭제 금지) |

### 7.2 🔴 dt 하한 규칙 — V-1 실측 근거

| 항목 | 실측(20260915 세션, Trial#1 Right) |
| --- | --- |
| 실측 프레임 간격 | **59.1 ms**(16.93 fps) |
| `time_s`(벽시계) 인접 행 간격 — 최소 | **1.747 ms**(프레임 간격의 1/34) |
| dt<20 ms 쌍의 비율 | **22.4%** |
| PV가 찍힌 쌍 | dt=1.747 ms, \|Δp\|=13.884 mm → **7.947 m/s** |
| 같은 쌍을 59.1 ms로 보면 | 0.235 m/s |
| **프레임 시계로 재계산한 PV** | **0.605 m/s** |

**결함 3중 조합:** ① 타임스탬프가 벽시계 ② 속도식이 `|Δp|/max(dt,1e-4)`(=하한 0.1 ms가 사실상 무제한 증폭) ③ 집계가 `max()`.
**동결:** (1) dt는 장치/프레임 타임스탬프에서만 (2) `dt_min`=세션 실측 중앙 간격의 절반(≈30 ms), 미만 쌍 제외하고 제외 수를 Q에 기록 (3) **dt_min 미만 쌍 수를 `trials_summary`에 남긴다** (4) 이 1~3 구현 전까지 **`PV`(peak)를 보고하지 않는다**.

⚠️ 임계값을 **ARAT 점수·VLM 정답률로 고르지 않는다.** 본평가 전 동결.

> 🔴 **Q1 = 0.3 (동결, 2026-09-30).** 파일럿(20260915, 16시행)의 유효 depth 비율은 **0–63%, 중앙값 ≈0.30**(Trial#7·8은 **0%**)이었다. **0.7은 모든 시행을 탈락**시킨다. ⚠️ 이 파일럿 값은 **원시 depth 미저장(D-16)** 파생값이라 **과소추정**일 수 있다 → **0.3은 잠정 동결값**이며, **치구 135기록·개발군 9명의 분포가 크게 다르면 본평가 전 동결 회의에서 1회 조정**하고 그 후 변경하지 않는다. Q3(샘플 수)와 역할이 겹치므로 **Q1·Q3을 함께 보고**한다.
> ✅ **A3의 게이트는 자동이다(2026-09-30 재설계).** 자동 검사 = **Q1~Q4 + 손-일관성**. **Q5(사람 주석)는 게이트에서 제외**하고 **검증 지표**로만 쓴다. 따라서 A3는 정확히 **"자동 품질 선별"** 이다.
> 🔵 **사람 개입 지점(정직):** 게이트 자체는 자동이고, 사람이 개입하는 곳은 (i) **Q5 가림 주석**(선택·검증) (ii) **가림 주석 대조 검출률** (iii) **치구 측정**이다.
> 🔵 **그럼에도 Q5를 남기는 이유:** 자동 게이트의 타당성을 **사람 판단과 대조**해 검출률로 보고하기 위함이다(§5.2). Q5를 **아예 빼도** A3는 성립하지만, 그러면 **"가렸다 못 본 시행을 걸렀는지"의 검증 근거가 사라진다** → **최소한 VLM에 들어가는 120영상에 대해 시행 단위로**(프레임별 아님) 사람 확인을 권한다.
> 🔴 **Q3의 시간 편향 점검:** `n<50 → 보류`는 **빠르게 끝나는 정상 수행**을 체계적으로 제외할 수 있다. 개발 단계에서 **수행시간 분위별 보류율**을 보고하고, 편향이 크면 Q3를 시간 조건과 결합하거나 **M1 요약 정의**를 수정한다.
**Q가 재지 않는 것:** Q는 정확도가 아니라 **"믿을 만한가"의 대리 지표(개연성·완전성)** 다. 따라서 ❌ "교정된 mm 오차 확률" ❌ 중증도 ❌ "가린 손끝 3D 검증됨"으로 주장할 수 없다. **Q의 타당성은 ① 치구 135기록 ② 가림 주석 대조(검출률) ③ 이 연구 자체(PR-2)** 로만 주장한다.
**알려진 맹점:** 접촉 순간 손가락 패드와 물체 표면 depth가 거의 같으면 **랜드마크가 물체에 찍혀도 기하 검사로 구분 불가** → 결과표에 **검출률을 병기**하고, 낮으면 **M1 정의 변경** 또는 T2 결론 제한.

> 🔵 **“MGA·tMGA·SPARC 3개면 충분한가?” → MGA는 통과, tMGA는 탈락, SPARC는 판정 불일치다.**
> 🔵 **SPARC 재검·규명 완료(2026-09-30, `check_sparc_filter_sensitivity.py` + 시간축 3종 대조)**: 불일치 원인은 **앱 버전별 SPARC 알고리즘 차이**였다(D-21). `clock_v3`(=참조구현 일치 검증) 정의로 재계산하면 **MDC 43.3%(좌)/46.9%(우) → C2 통과**, 추가 LP 1.5–1.0 Hz에서 27–35%. 구 앱(`fixed.py`)의 92%는 **다른 함수(적응컷오프·주기평균)** 의 값이다.
> ✅ **SPARC 구현·cutoff 사전 고정:** 구현 = **`clock_v3`의 `sparc()`**, **추가 pre-filter 없음**(원신호 왜곡 방지), `fc = min(10, fs/2)`. 민감도로 **1.5 Hz pre-filter 병기**. → **C2 통과**하므로 **SPARC를 조건부 편입**한다(ARAT 단일 과제 + 자동 분할에서 최종 확정).
> 🔴 **필터의 의미 희석(정직):** SPARC는 **고주파 거침**을 재는 지표이므로 LP를 강하게 걸면 **측정 대상 자체가 줄어든다**. 그럼에도 우리 데이터의 고주파는 생물학적 떨림보다 **추적 노이즈**에 가깝다 → 어느 정도 필터는 정당하다. 그러나 **cutoff 선택이 곧 지표 정의**이므로 **사전 고정**해야 하고, **13.4 fps에서는 Nyquist가 6.7 Hz**라 1–3 Hz 구간의 분리가 제한적이다.
> 🔴 **비장애 세션(20260915)은 SPARC 계산 불가:** 시간축이 **18/18 그룹에서 비단조(min dt = 0.000 s)** → 구 앱 시계 결함(V-1). **지표 문제가 아니라 시계 문제**다.
> ✅ 나머지 결론은 유지: tMGA는 **C2 탈락**(좌 184.9% / 우 139.7%), 대안은 **MGA + TAM_total** 또는 **K1_mp**다.
> 🔵 **tMGA:** 자유 개폐(주기 3–16개)에서는 정규화 시점이 불안정(**C2 초과**) → **단일 reach-to-grasp(ARAT) + 자동 분할**에서 재검정해야 한다.
> 🔵 **반복성은 인구집단에 따라 바뀐다**(Index_ROM: 비장애 17.2 → 환자애프터 55.3) → **환자군에서 반드시 재검정**한다.
>
> 🔴 **SPARC의 현재 지위(정직):** 파이프라인 구현은 원저자 참조구현(`siva82kb/SPARC`)과 수치 일치를 확인했고(2026-09-29, clock_v3 rev 3.1+), 47차 감사에서 **"SPARC 통과" 주장은 철회**되었다. 상태는 **"구현 검증 완료 · 편입 여부는 재평가 필요(C2 재산출 대기)"** 다. **본 실험의 커밋된 입력은 `K1_mp`·`TAM_total`(+`MGA` 보조)이며, SPARC는 편입 조건을 통과할 때만 탐색적으로 병기한다**(§7.5).

## 8. 실험 조건 A0~A4 + R + 오류 주입

| 조건 | 입력 | 확인 |
| --- | --- | --- |
| **A1** | RGB 영상 + 과제 지침 + T | 기준선 |
| **A2** | A1 + **M1·M2 전부**(+M3·M4 해당 시) | 숫자 추가 효과 |
| **A3** | A1 + **Q 통과분(M1·M2)** | **품질 선택(PR-2)** |
| **A4** | A3와 같은 수치·지침·시간, **RGB 제외** | 영상의 추가 가치 |
| **A0** | 로지스틱 회귀: M1·M2(**장애인 내 정규화**)·Q 요약·T·과제 ID | 경량 통계모형 대조 |
| **A0-time** | T·과제 ID만 | 시간 단서만의 효과 |
| **R** | A2에서 A3와 **같은 양**을 품질 무관하게 제거 | "숫자를 덜 보여준 탓" |

> **A0 정규화 정의:** M1·M2는 이미 **시행당 스칼라 1개**이므로 시행 내 정규화는 성립하지 않는다. 정규화 단위는 **장애인 내**(같은 장애인 시행들 사이)로 하고, 분석 단위가 장애인이므로 이를 기본으로 한다.
> **R 배정(수정):** 지표별로 A3 보류 수 n을 세고, **원래 값이 존재하는 전체 후보 P(하드 결측 제외)** 에서 **무작위로 n개**를 골라 null로 만든다. ⚠️ **"A3가 보류하지 않은 시행"으로 후보를 제한하면 품질과 상관된 대조군이 되므로 금지**한다. seed 3개(20260922/23/24) → 장애인별 평균. 하드 결측은 P에서 제외되어 모든 조건에서 유지된다.

### 8.1 오류 주입
- **bias:** 해당 시행 값 전부에 **+1u / +3u**(**지표별 u — M1=mm, M2=deg, M4=무차원**). ⚠️ **주입 방향은 “나빠지는 방향”**: **M1·M2는 +**, **M4(SPARC)는 −**(더 음수=더 거침) — 코드 `SIGN={m1:+1,m2:+1,m4:−1}` · **burst:** 한 시행의 값만 **+3u**
- 대상: **A2, A3만** · 수준: 원래 + 주입 4수준
- **컴퓨트(2모델):**

| 구성 | 산식 | 횟수 |
| --- | --- | --- |
| A1·A2·A3·A4 | 120×4 | 480 |
| R(seed 3) | 120×3 | 360 |
| 주입 신규(bias_1u·bias_3u·burst_3u × A2·A3) | 120×3×2 | 720 |
| 반복(장애인 4명 A1·A3 1회 추가) | 4×2×3×2 | 48 |
| **1모델 합계** | | **1,608** |
| **2모델 합계** | 1,608×2 | **3,216** |
| (선택) Pareto sweep 3임계값 | 3×120×2 | +720 → 3,936 |
| (선택) A1+ 교란 통제(D-17) | 120×2 | +240 |

⚠️ **burst를 프레임 단위로 정의하지 않는다**(3프레임 burst는 P95를 ≤+2.6%밖에 못 움직여 모델 입력이 안 바뀜). ⚠️ `u/기저 P95>0.10`에는 "이미 오염" 라벨.

## 12. 표본 크기와 검정력 + 후속 과제(정상 파지 서브타이핑)

### 12.1 표본 크기(정직한 한계)

**대응 비교, 양측 α=.05, 검정력 .80** (`dz=(t(α/2,df)+t(β,df))/√n`)

| 장애인 n | 검출 가능 dz | SD(Δ)=1점 | 2점 | 3점 |
| --- | --- | --- | --- | --- |
| 12 | 0.89 | 0.9점 | 1.8점 | 2.7점 |
| 15 | 0.78 | 0.8 | 1.6 | 2.3 |
| **20** | **0.66** | 0.7 | 1.3 | 2.0 |
| 24 | 0.60 | 0.6 | 1.2 | 1.8 |

- 12명이면 0.9점 차이(=척도의 30%)만 검출 → **"큰 효과의 방향 탐색"만 가능, 소효과 검출 불가**를 논문에 명시.
- **CI 폭이 실질 제약:** 12명·SD=1.0이면 95% CI 반폭 ±0.64점. **n=20으로 올려 dz 0.66·CI 반폭 ±0.47 확보.**
- Wilcoxon을 쓰면 n이 더 필요(Δ=0.75에서 t 12명 → Wilcoxon 약 20명).
- 🔴 **Q1 = 0.3으로 동결(2026-09-30, §7.3).** 치구·개발군으로 **확인**하고, 동결 회의에서만 1회 조정. 개발군이 작으면 임계값이 불안정하므로(개발 3명 SD 0.101 → 24명 0.051) **Pareto sweep(Q1 임계값 민감도)을 1급 결과로 보고**한다.
- ⚠️ **dz=0.66은 Holm 보정 전·paired t 기준**이다. 주 검정을 Wilcoxon으로 하면 더 많은 n이 필요하므로 **Holm k=3·Wilcoxon 기준에서는 검정력이 낮아짐을 명시**한다.
- 비장애인 검증 10명의 ICC 95% CI 폭=0.67 → **16명으로 확대**(CI 하한을 보고).

### 12.2 🔵 후속 과제(커밋 범위 밖) — 정상 파지 서브타이핑과 시너지 매니폴드 이탈도

> **중요:** 아래는 **본 실험의 확증 결과가 아니다.** 본 실험은 위 §3~§11의 수치 주입·게이팅 인과실험이다. §12.2는 **후속 과제로 별도 등록**하며, **"검증된 설계"로 쓰면 안 된다.** 근거와 프로토콜을 여기에 남겨 재현 가능하게 한다.

**동기(문헌 근거, §2.6):** ① 정상인도 개인 고유 파지 패턴을 보이고(Herbst 2020), ② 정상 참조는 (a)공통 core + (b)개인 조합의 2층 구조이며(Gracia-Ibáñez 2020), ③ 장애인은 정상보다 1개 많은 차원(보상 차원)을 쓴다(van Kordelaar 2012). ④ **뇌졸중 파지 운동학의 비지도 서브타이핑은 문헌상 공백**이다(§2.6-3).

**등록할 설계(잠정, 본 실험 종료 후 데이터로 확정):**
1. **특징 벡터(6차원 후보, 사전등록 대상):** `[MGA_n, tMGA_n, RGC_lag, SPARC*, Asym_thumb-index, Closure_ratio]`
   - **근거 매핑(정직):** `MGA_n`←Mason 2001·Santello 1998(1st 시너지=손 전체 개폐) / `tMGA_n`←Santello 2002(도달 중 preshaping)·Jeannerod 1984 / `RGC_lag`←개념적으로 Schwarz 2025(관절 타이밍)·van Kordelaar 2012(협응 이탈)이나 **그들은 `tMGA−tPV`를 직접 측정하지 않았다**(개념적 인접 근거) / `Asym_thumb-index`←Herbst 2020(엄지 최다 기여)·Jarque-Bou 2019(시너지#3 엄지 대립)이나 **비대칭 지수 자체는 그들이 정의하지 않았다** / `Closure_ratio`←Pratap 2024(안정 파지 전 형상 유지)이나 **직접 측정 아님**.
   - **`SPARC*`:** SPARC의 근거는 **Balasubramanian 2015 하나**다. **Alt Murphy 2011은 SPARC를 쓰지 않았다**(그 논문의 >94.7%는 NMU·TMT·팔꿈치 각속도 기준).
   - **`tMGA_n` 실측 주의(2026-09-30):** 자유 개폐 과제에서는 **C2 미달(140–185%)** → **단일 reach-to-grasp + 자동 분할**에서만 후보로 쓴다.
2. **차원·K 결정 규칙(사전 명시):** 차원은 **BIC + silhouette + bootstrap stability**로 결정하고, **분산 80% 기준과 eigenvalue>1 기준을 병기**한다(선행 연구가 이 기준들을 함께 씀). **K는 BIC·bootstrap으로** 정한다(Romero 2010: Gaussian ≤3개로 충분 → K를 유리하게 고르지 않도록 규칙 고정).
3. **baseline(필수):** 피험자별 **PCA+varimax+hierarchical clustering**(Jarque-Bou 2019/Gracia-Ibáñez 2020 재현)을 **반드시 함께 돌린다.** GMM 단독 주장을 막는다.
4. **이탈도 지표(제안·미검증):** ① 마할라노비스 거리 `D_M = sqrt((x_p−μ_k)^T Σ_k^{-1} (x_p−μ_k))` ② 시너지 부분공간 투영 잔차 `E_proj = ||x_p−x̂_p||₂/||x_p||₂ ×100(%)` ③ 시간 협응 `ΔRGC=|RGC_patient−μ_RGC,matched|`. **모두 "제안 지표"로 표기**하며, **PCA 5성분(Alt Murphy)·4-PC 77.3%(Gracia-Ibáñez)·12시너지 80%(Jarque-Bou)를 baseline으로 비교**한다.
5. **표본 조건:** 안정적 시너지/군집은 77명 규모(Jarque-Bou)에서 나왔다. 소표본(Romero N=5, Pratap N=10)은 탐색적이다. → **정상 참조모형을 실제로 만들려면 별도 코호트 60~100+명**이 필요하다(Jarque-Bou 77명, UbiPhysio 104명). **본 실험의 비장애인 22명(개발 6+검증 16)으로는 부족하다.**
6. **특징 사전등록:** Herbst 2020의 **특징 선택 ~45% 민감도** 때문에 특징 목록을 사전등록하고 **민감도 분석·Leave-One-Feature-Out**을 보고한다.
7. **센서 한계(정직):** 선행 강결과는 **접촉식 관절각 측정**이다. 우리는 **RGB-D 무마커**로 관절각 추정 오차가 크다(§2.7). 따라서 §12.2는 **기하학적 랜드마크 거리(MGA)와 시간 지연(RGC_lag) 중심**으로 하고, **개별 관절 미세각 추정을 지양**한다.

> **면담 방어 문장(그대로 쓸 것):** *"본 실험은 수치 주입·게이팅의 인과 효과를 측정하는 확증 연구이며, 정상 GMM 서브타이핑은 범위 밖의 후속 과제다. 후속 과제에서는 차원과 K를 BIC·silhouette·bootstrap으로 데이터에서 결정하고, 피험자별 PCA+varimax+계층군집을 baseline으로 반드시 포함하며, 정상 참조모형 구축에는 별도 60~100명 코호트가 필요하다."*

### 15.1 실증 검증 상태
**본 ARAT 2과제 프로토콜의 전체 과정 검증과 본 실험은 미실시.** 다만 **기술 파일럿은 존재**한다(비장애인 2명·18시행, 20260915/16 세션 + **환자 2세션 20260929**, 실제 RGB 프레임 — `capstone/호진파일/outputs/데이터_저장/`). ⚠️ **저장된 범위는 세션마다 다르다:** 20260915에는 **RGB 영상(.avi)** 이 있으나 **20260929 환자 2세션에는 영상이 없다**; **원시 depth 프레임은 어느 세션에도 없다**. 또 이 파일럿은 (a) **ARAT 2과제 프로토콜이 아니고**, (b) **시행 경계를 사람이 잘랐으며**(§6.3 금지 위반), (c) 파생 지표(`MGA_mm_3D_cal` 등)는 §7.1 파이프라인 출력이 아니다. → **정확한 상태: “기술 파일럿은 있으나, 새 ARAT 프로토콜의 end-to-end 검증·본 실험은 0건.”**
