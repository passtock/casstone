## 3. S5 — 실험 세팅 (3칸 · 각 3.80 × 1.62 in, 가로 2.35:1) ★ 최우선

**피드백 ①에 대한 답.** 발표에서 질문이 가장 많이 나오는 곳. 실제 촬영이 원칙.

### #8 실험 세팅 전경
- **무엇:** 실험 공간 전체를 **측면 30–45°** 에서 찍은 사진
- **한 프레임에 전부 들어와야 함:**
  1. 카메라(D455) + 삼각대, **작업거리 0.65–0.85 m**
  2. 테이블(높이 75 cm)
  3. **선반(테이블면에서 37 cm)** — 상단이 잘리면 안 됨
  4. 의자(좌면 46 cm, **팔걸이 없음**)
  5. 대상자 착석 자세(등받이 접촉)
  6. 물체(블록/구슬)와 뚜껑
- **주의:** 가로 구도. **팔걸이 있는 의자를 쓰면 사진으로 티가 남**
- **가점:** 사진 위에 ①카메라 ②37 cm ③75 cm ④46 cm를 **화살표+라벨**로 얹기

### #9 배치 도면
- **무엇:** top view 평면 배치도 (PowerPoint 도형으로 제작)
- **포함:** 테이블 75×76×49 cm · 물체 시작 = **정중시상면과 액와선의 중간** · 선반 37 cm(근위연 20±5 cm) · T1 경로(블록→선반) · T2 경로(하부 뚜껑→상부 뚜껑) · 카메라 위치 + 작업거리 + 하향 30–45° · 대상자 좌석
- **주의:** 치수 단위(cm) 전부 표기. 화살표 = 동작 진행 방향

### #10 환측 손 파지 장면
- **무엇:** 실제 파지 순간 클로즈업
- **구도:** 손 + 물체가 화면 60% 이상, **상완·전완도 일부** (팔로 집는 동작임이 보이게)
- **반드시:** 엄지·검지 **패드가 물체에 맞닿은 순간**
- **주의:** 손만 있으면 "손 크기 문제"가 안 보임 → **물체와 손을 같은 크기로** 나란히

## 4. S6 — 두 과제 선정 근거 (1칸 · 2.00 × 1.34 in, 약 1.5:1)

### #11 ARAT 위계 도식
- **무엇:** ARAT 4개 하위검사와 난이도 순서를 한 장에
- **반드시 보여야 할 것:**
  - 4개 소척도 막대: **Grasp(1–6) / Grip(7–10) / Pinch(11–16) / Gross(17–19)**
  - 각 소척도 안에서 **왼쪽 = 최난이도** (건너뛰기 규칙이 시작되는 지점)
  - 소척도 사이 **경계선**을 굵게 → "건너뛰기는 여기서 멈춘다"
  - **T1 = 3번(Grasp)**, **T2 = 12번(Pinch)** 위치를 화살표로 표시
- **한 줄 주석:** "Koh 2006: 19개 중 유일한 위계 위반 = pinch ball bearing"
- **주의:** 소척도 경계가 안 보이면 이 그림의 목적이 사라짐

### #16 K2 개념도
- **무엇:** 손목 표면점(0번)의 **3D 이동 속도**
- **반드시:** 0번 강조 / 인접 두 프레임(궤적선 위 2점) / **속도 벡터 화살표 + `K2 (mm/s)`**
- **금지 표기:** `민첩성` · `dexterity` · `신경 회복` · `손가락 속도`

### #17 Q 판정 예시
