# ARAT 채점자 룰북 (문항 3·12) — 채점자 교육용

> **근거:** Yozbatiran N, Der-Yeghiaian L, Cramer SC (2008). *A Standardized Approach to Performing the Action Research Arm Test.* Neurorehabil Neural Repair 22(1):78–90. DOI [10.1177/1545968307305353](https://doi.org/10.1177/1545968307305353) (부록 Manual)
> **작성:** 2026-09-30 · **지위:** 이 문서는 **채점자 교육·현장 사용**용이다. 연구 정본은 `outputs/실험계획서_최종본.md`.
> **중요:** 우리는 ARAT 하위검사 전체(19문항)를 돌리지 않고 **문항 3(블록)·문항 12(구슬)만** 시행한다. 따라서 **ARAT의 건너뛰기(skip) 규칙은 적용하지 않는다.** 이 점을 논문에 명시한다.

---

## 0. 우리가 하는 두 문항 (물성·배치)

| | ARAT | 대상 | 무게 | 배치 | 3점 기준 |
|---|---|---|---|---|---|
| **T1** | **문항 3** (Grasp 하위검사) | 목재 블록 **5 cm** | **55 g** | 테이블 → **선반(37 cm)** | **5초 이내** 정상 수행 |
| **T2** | **문항 12** (Pinch 하위검사) | 구슬 **⌀1.6 cm** | **5.4 g** | 하부 뚜껑(근위연 5 cm) → 선반 위 **상부 뚜껑** | **5초 이내 + 엄지·검지 패드 맞섬** |

- 환경: 테이블 높이 75 cm(너비 76, 깊이 49) · 의자 좌면 46 cm(팔걸이 없음) · 선반은 테이블 면에서 **37 cm** · 물체는 정중시상면과 액와선의 **중간**
- 자세: 의자 등받이에 **몸통 계속 접촉**(묶지 않음), 발바닥 지면, 머리 중립
- **한 손만** 사용. 소척도마다 **비환측 먼저** 시행.
- ⚠️ **구슬 지름:** Yozbatiran Table A2 = **1.6 cm**. Lyle 원형 채점지(ksu ARAT form)는 **1.5 cm**로 기재 → **출처 간 불일치**. **실물 구슬을 캘리퍼로 측정해 실제 값을 기록**한다(D-19).

## 1. 지시문 (그대로 낭독)

- **T1:** “grasp the block that I have placed here, lift it up, and place then release it on top of that shelf.”
- **T2:** “grasp the marble using these fingers, lift it up, and place it in the tin on top of the shelf.”
  - *(“these fingers” = 엄지와 검지를 시범으로 보여준다)*

**금지:** 물체를 잡아주거나 손을 유도하지 않는다. 물체를 비시험측 손이나 다른 물체로 고정하지 않는다.

---

## 2. 점수 정의 0–3 (ARAT 원문 기준)

> ARAT 원문 요약: “3 = 정상 수행(**5초 이내** + 정상 손·팔 움직임 + 정상 자세) / 2 = 완료했으나 **큰 어려움 또는 비정상적으로 오래 걸림(5–60초)** / 1 = 60초 내 **부분 수행** / 0 = 60초 내 **어떤 부분도 못함**.”

| 점수 | 조건 |
|---|---|
| **3** | **5초 이내** 완료 + **정상 손 움직임 + 정상 팔 움직임 + 정상 자세**. (T2는 **손가락 패드**로 맞섬) |
| **2** | **완료**했으나 ⓐ 손 움직임 비정상(예: 잘못된 파지), ⓑ 팔 움직임 비정상(예: 팔꿈치가 필요만큼 굽지 않음), ⓒ 자세 비정상(예: 몸통이 등받이에서 완전히 떨어짐), ⓓ **5–60초** 소요, ⓔ (T2) **놓기 실패** 또는 **해제 시도 중 물체가 떨어짐** |
| **1** | **60초 내 부분 수행.** **손으로 들어올린 경우에만** 1점. 물체를 손등으로 밀거나 다른 물체에 고정해 옮기는 것은 **부분 수행이 아니다**. (예: 들었으나 **선반 높이에 못 미침**) |
| **0** | **60초 내 어떤 부분도 못함.** 손을 열어 물체 크기만큼 벌리지 못함 / 비시험측으로 물체를 조작 / **자발적 손 개방 없이** 물체를 움직임 |

---

## 3. 🔴 낙하·최선수행 규칙 (가장 많이 틀리는 부분)

> **ARAT 원문(일반 채점부):** “**The score is based on the best performance. A subject is not penalized if a testing object is dropped and relifted.**” (점수는 **최선 수행** 기준. 물체를 떨어뜨렸다가 **다시 들어 올리면 감점하지 않는다.**)

| 상황 | 채점 |
|---|---|
| **(a) 떨어뜨린 뒤 60초 내 다시 집어 과제를 완료** | **완료로 인정.** 낙하 자체는 감점 아님 → 품질·시간에 따라 **2점 또는 3점** |
| **(b) 60초 안에 다시 집지 못하고 미완** | **1점** (부분 수행) |
| **(c) 목표(뚜껑)에 놓지 못함 = 해제 실패**, 또는 **해제 시도 중 물체가 뚜껑 밖/선반 밖으로 떨어짐** | **2점** |
| **(d) 과제를 성공적으로 마친 뒤** 선반/뚜껑에서 물체가 **튕겨나가거나 떨어짐** | **감점 없음** (Grasp·Pinch 하위검사 원문) |

**즉:** “떨어뜨리면 무조건 1점”이 **아니다.** **다시 집어 끝냈는지**와 **60초 안에 끝났는지**를 본다.

---

## 4. T2(구슬) 특수 규칙 — 훨씬 엄격하다

> **ARAT 원문(Pinch 하위검사):** “correct hand movement components (**finger opposition**) must be present to score more than 0” · “**a score of 3 can only be generated if the finger opposition specifically uses the pads of the fingers**.”

| 조건 | 결과 |
|---|---|
| **엄지–검지 맞섬(opposition)이 아님** (예: 손바닥으로 쥠, 네 손가락으로 감쌈) | **0점** (다른 점수 요소와 무관) |
| 맞섬이지만 **손가락 패드(pad)가 아님** (예: 옆면·손톱·관절로 접촉) | **최대 2점** (3점 불가) |
| 맞섬 + **패드** + 5초 이내 + 정상 자세 | **3점** |

## 5. 채점 시트 기록 방법

`S07_score.csv` (또는 `participant_score.csv`) 한 행 = **한 시행**. 열 설명:

### 5-1. ARAT 원형 란 (점수는 여기만 본다)
| 열 | 값 |
|---|---|
| `participant_id` | 참가자 ID |
| `side` | `R` / `L` (검사한 손) |
| `task` | `T1`(문항 3) / `T2`(문항 12) |
| `phase` | `practice` / `main` |
| `trial_index` | 시행 번호 |
| `time_s` | 실제 소요 시간(초). **5초 경계 판정에 필수** |
| `score` | **0 / 1 / 2 / 3** (위 §2–§4) |
| `rater` | 채점자 성명/코드 |
| `blinded` | 눈가림 여부(1/0) |

### 5-2. 분석용 부가 기록 란 (점수와 무관, 따로 기록)
| 열 | 값 | 왜 |
|---|---|---|
| `finger_used` | T2: 사용한 손가락 (예: `thumb+index`) | T2 채점 기준의 일부 |
| `pad_used` | T2: `Y`/`N` — 패드로 집었는가 | 3점 가능 여부 |
| `released` | `Y`/`N` — 목표 위치에 놓았는가 | 해제 실패 판정 |
| `dropped_then_relifted` | `Y`/`N` — 떨어뜨렸다가 **다시 집어 완료**했는가 | 최선 수행 규칙 |
| `release_failed` | `Y`/`N` — 해제 실패(2점 사유)를 겪었는가 | 판정 추적 |
| `reattempts` | 재시도 횟수(정수) | 낙하·재시도 추적 |
| `voluntary_lift` / `reached_target` | `Y`/`N` | 1↔2↔3 구분 |
| `abnormal_arm` / `posture_loss` | `Y`/`N` | 2점 사유 |
| `not_assessable` | `Y`/`N` — 영상으로 채점 불가(가려서 못 봄) | 품질 검증용 |
| `note` | 자유 기록 | 애매한 사례 |

⚠️ `finger_used`·`pad_used`는 **T2 채점 기준의 일부**이지만, **VLM 모델 입력에서는 제외**한다.

## 6. 채점자 체크리스트 (시행마다)

- [ ] 몸통이 등받이에 **계속** 닿아 있었는가? (떨어지면 2점)
- [ ] **5초 이내**였는가? 아니면 5–60초(2점)인가, 60초 초과(0/1점)인가?
- [ ] **손으로 들어올렸는가**? (밀기·고정은 부분수행 아님)
- [ ] 떨어뜨렸다면 **다시 집어 끝냈는가**(완료 인정) vs **못 끝냈는가**(1점)?
- [ ] **놓기 실패**가 있었는가? (2점)
- [ ] (T2) **엄지–검지 맞섬**인가? **패드**인가?
- [ ] `time_s`·`dropped_then_relifted`·`release_failed`·`pad_used` **칸을 채웠는가**?

## 7. 자주 하는 실수

1. **"떨어뜨렸으니 1점"** → 틀림. **다시 집어 끝냈으면 완료**.
2. **"완료했으니 3점"** → 틀림. 자세·손/팔 움직임·시간(≤5초)·(T2) 패드를 **모두** 만족해야 3점.
3. **T2에서 손바닥으로 쥐어도 점수를 줌** → 틀림. **맞섬 아니면 0점**.
4. **T2에서 옆면으로 집었는데 3점** → 틀림. **패드가 아니면 최대 2점**.
5. **`time_s`를 안 적음** → 2점/3점 경계를 사후에 판정할 수 없다.
6. **시트를 나중에 한꺼번에 채움** → **시행 직후** 채점·기록한다(ARAT 원칙).
