### 0-2. ⚠️ 사용자 배경 메모(GMM 6차원 서브타이핑)와 현재 실행계획은 **다르다**

프로젝트 배경 설명문은 **"GMM 기반 6차원 운동학 서브타이핑 + 정상 시너지 매니폴드 이탈도"** 와 **"14프레임 + 서브타입 백분위 JSON 주입 2-Stage"** 를 말한다. 현재 실행계획 **v13.2** 는 이 둘을 **주 연구 범위에서 제외**한다:

- **정상 GMM·군집화·시너지 매니폴드는 후속 과제**로 별도 등록(`v13.2 §12.2`). 차원 수·K는 **데이터로 결정**(BIC·silhouette·bootstrap)하며, 정상 참조모형은 별도 60~100+ 코호트가 필요.
- **14프레임은 상한 64프레임(앞 5초 @10 Hz 50 + 5초 초과분 2 Hz)으로 대체**됐다. 14프레임(≈0.3초)은 0.3초 사건에 0.8프레임밖에 못 넣는다.
- **"6차원"은 확정 사양이 아니다.** 9/30 군집화 문헌조사에서 보고된 **군집화 차원이 2~12로 분산**(Santello 2, Pratap 3, Gracia-Ibáñez/van Kordelaar 4, Alt Murphy 5, Jarque-Bou 12)임을 확인 → "6차원"은 **문헌 근거가 아니라 목표 표현**임을 명문화했다.

이 구분은 **사용자 본인이 2026-09-22에 지적해서 확정된 것**이다: *"내가 손 궤적을 6개 쓸거라고 정했니? 데이터 보고 정하기로 한 거 아니야?"* → 증거맵 상단에 **v5 범위 주의문 + 표현 대응표**가 삽입됐다.

> **따라서 이 브리핑은 두 층을 구분한다.**
> - **(프로그램 층)** GMM 서브타이핑·정상 매니폴드·서브타입 백분위 주입 = 큰 그림 / 후속 과제
> - **(실행 층)** v13.2 = 10주 안에 끝낼 수 있는 품질 선별 → VLM 채점 비교 실험
>
> 두 층을 섞어 발표하면 재차 "범위 초과" 지적을 받는다.

### (C) 계층적 임상 사다리 + Brunnstrom 1:1 매핑 (원문 §1.1)

- **사다리:** **진단(Baseline, Task 1)** → **기초 일상동작(Power Grasp, Task 2)** → **고난도 협응(Precision/Opposition, Task 3)** → **로봇 중재(Intervention, Task 4)** → "완결된 임상 재활 사이클" + "평가와 치료의 단일 플랫폼 융합".
- **Brunnstrom Hand Stage 매핑:**
  - **Stage 3 (집단 굴곡기, Mass Flexion)** — 주먹은 쥐나 스스로 펴지 못함 → **Task 1**에서 굴곡-신전 불균형·굴곡 공동운동 정량화
  - **Stage 4 (공동운동 이탈기)** — 굵은 물체 파지 가능, 엄지 부분 신전 → **Task 2**에서 파워 파지 안정성
  - **Stage 5 (독립 조작·3D 대립기)** — 구형 파지·자발적 전 범위 신전 → **Task 3**에서 엄지 대립 협응·개구 조절
- **의도적 제외한 파지 형태(원문 §1.3):**

| 파지 유형 | 임상적 제외 사유 | 비전/공학적 제외 사유 |
|---|---|---|
| **Tip Pinch**(손끝 집기) | FMA 56~66점(최후기) 전용, 중등도(20~55점) 수행 불가 | 손끝 접촉 시 랜드마크 겹침(self-occlusion)·ID 스위칭 |
| **Key Grasp**(측면 집기) | 엄지-검지 측면 2D 단순 운동, 5지 협응 반영 부족 | 검지 요측 가림으로 MCP/PIP 정밀 3D 각도 산출 불가 |
| **Disk Grasp**(원판 파지) | 평면 원판은 손목 신전각에 극도로 민감해 오차 | 단안 카메라 앵글에서 손가락 노드 은폐율 **70% 초과** |

### (D) 물체 규격·세부 수행 프로토콜 (원문 §2, 9/4 영문판 §4)

- **원통:** ⌀5.0 cm · 높이 12 cm(9/4판은 높이 10 cm) · **무광 목재(mat의 specular 반사 억제)**
- **구:** ⌀7.0 cm(야구공 규격) · 무광 목재
- **측면집기 블록(9/4 추가):** 두께 **1.5 cm** × 폭 4 cm × 높이 7 cm, **시상면(sagittal) 정렬** → 엄지를 내측·검지를 외측으로 강제해 **엄지-검지 벌림이 40° 상향 카메라에 정면 노출**(self-occlusion 회피). **Stage 4의 핵심 판별 과제.**
- **수행 프로토콜(원문):** 양손 동시 도달 → 파지 → **5 cm 수직 들어올림** → **2초 유지** → 테이블 복귀, **8회 반복**
- **왜 8회인가(9/4 영문판 §4.2):** 워밍업·추적 드롭 제거를 위해 **최소 5회 안정 반복**이 필요(ICC>0.85 보장), 그러나 Stage 4~5 환자는 **10~12회 초과 시 신경근 피로**로 경직·체간 굴곡 보상이 나타남 → **8회/과제 = 총 24회 기능 반복**이 신뢰도와 피로 임계의 균형점. 평가 시간 15분 이내.

  - **선정:** **Brunnstrom Hand Stage 3~5**, **FMA-UE 수부 20~55점**(경도~중등도), **MMSE ≥ 24**
  - **제외:** 수부 관절 중증 구축(가동범위 **50% 이상 제한**), **편측 무시**(hemispatial neglect), 개방성 상처·심한 통증
- **표본 크기:** G*Power 3.1, Paired t-test, **Cohen's d = 0.65~0.75**, α=0.05, 1−β=0.80 → 최소 **13~21명** → 탈락률 고려 **각 군 15명, 총 30명**
- **윤리:** 협력 임상기관(**에스포항병원 등**) **IRB** 승인 후 개시, 서면 동의, **소프트 공압 안전 제어**(장애인별 최대 내약 공압 제한, 안전 릴리프 밸브 + E-Stop)
- **설계:** **2(집단: 비장애 vs 뇌졸중) × 2(시점: Pre vs Post) 혼합 설계(Mixed Design)**

### (G) 측정 변인·산출 수식 (원문 §4.5)

1. **14개 관절각(θ):** `θ = arccos[(v_ba · v_bc) / (‖v_ba‖‖v_bc‖)] × 180°/π` — 엄지 MCP/IP + 4지 MCP/PIP/DIP
2. **TAM(총 능동 운동범위):** `TAM = Σ_f [max(θ_f) − min(θ_f)]` (ASSH 표준, °)
3. **MGA Ratio(%):** `max‖P_thumb_tip − P_index_tip‖ / ‖P_middle_MCP − P_wrist‖ × 100` (Jeannerod 1984)
4. **SPARC:** `−∫₀^{ω_c} √[(1/ω_c)² + (dV̂(ω)/dω)²] dω` (Balasubramanian et al., IEEE TNSRE 2015)
5. **양손 대칭도(SI %) + 제어 지연(τ_lag):** 건측·환측 각도 변화 일치도 + 상호상관 기반 지연(ms)

### (H) 2-Stage AI 구조 (원문 §7)

- **Phase 1 — 시계열 모델:** 입력 텐서 **X ∈ ℝ^{300×24}**(10초 @30fps). 구조 = `1D-CNN` → `Bi-LSTM` → `Attention Pooling` → **Multi-Head**:
  - Head 1 분류: **Brunnstrom Hand 3~5단계**(Softmax)
  - Head 2 회귀: **FMA-UE 손 파트 점수**(Smooth L1)
  - Head 3 이상감지: 경직/비정상 궤적(Sigmoid)
- **Phase 2 — VLM:** 핵심 프레임(Reach-Preshape-Grasp) + 확정 정량 점수 → **설명 가능한 임상 소견서**
- **"왜 바로 End-to-End VLM을 쓰지 않는가"(원문 §7.1):** *"VLM에 영상만 주고 FMA 점수를 매기라 하면 매번 달라지는 임의의 수치를 생성(hallucination)하여 의료기기로서의 신뢰성을 상실"* → **정량 점수와 자연어 해석의 역할 분리.**

### (I) 통계 분석 계획 (원문 §8)

- **동시 타당도:** 전자 고니오미터 vs 비접촉 **ICC(2,1) ≥ 0.85** + **Bland–Altman 95% LoA**
- **측정오차:** `SEM = SD × √(1−ICC)`, `MDC95 = 1.96 × √2 × SEM`
- **임상 상관:** 지표(TAM/SPARC/MGA) ↔ FMA-UE 손 점수 **Pearson/Spearman**
- **중재 유효성:** Pre/Post **Paired t-test(α=0.05)** + **Wilcoxon 부호순위** + 집단 간 **혼합 반복측정 ANOVA**
- **단일 세션 30분 흐름:** ① 사전 수기 FMA+고니오미터(5분, Ground Truth) → ② Pre 비접촉 평가(Task 1~3 각 3회, 5분) → ③ 공압 미러테라피(Task 4, 15분) → ④ Post 재평가(Task 1~3, 5분)

### (J) ★ 9/4 영문판 — 전환의 씨앗이 여기 있었다 ("Final Methodologically Verified Edition")

9/4 영문 제안서는 **이미 방향 전환의 절반을 담고 있다.** 원문의 6개 "verified methodological updates":

| # | 초안 | **9/4 확정** | 근거 |
|---|---|---|---|
| 1 | 카메라가 폐루프 구동에 관여 | **구동 제어는 flex 센서 전담, 카메라는 진단 전용으로 완전 분리** | 시각 처리 지연·장갑 재질에 의한 self-occlusion 제거 |
| 2 | 장갑 vs 표준요법 **동등성(equivalence) 대조** | **추가요법(add-on) 타당성 설계**: Group A(표준요법만) vs Group B(표준요법+장갑) | 윤리적 안전 + 예비 비모수 효과크기 추정 |
| 3 | 중재 전 1회만 평가 | **baseline + 4주 후 이중 측정** | 종단 회복 궤적 포착 |
| 4 | 미세 손가락 분리도 직접 정량화 시도 | **"신호대잡음비 붕괴로 분리도 제외"** → 견고한 거친 운동학 + **Feature-Grounded VLM** | 카메라 잡음 바닥 극복 |
| 5 | 단독 카메라 분류 모델 | **3-Arm 비교검증**: Pure Video / **Kinematic JSON Ablation** / Proposed Multimodal Grounding | **VLM score flatlining(arXiv:2511.17727)** 직접 대응 |
| 6 | 이분류 정확도·AUC | **비모수 통계 + Spearman rank + rank-biserial effect size** | 소표본 과적합 완화 |

- **개별 손가락 신전 과제는 "의도적 제외"** 명시 → **Brunnstrom Stage 4~5 경계(lateral/cylindrical/spherical)** 에 집중, Stage 6 고립 관절운동의 운동학적 잡음 함정 회피.
- **정상 참조모형(통계적):** black-box 신경망이 아니라 **정상군(n=20~30)의 표준화 Z-score**(`Z=(X−μ_norm)/σ_norm`), **정상 회랑(95% corridor, Mean±1.96SD, cubic spline)**, **Mahalanobis 거리**(`D_M=√((x−μ)^T Σ^{-1}(x−μ))`)로 다관절 협응 붕괴를 정량.
- **JSON 스키마 예시(원문 Listing 1):** `MGA_mm{measured, norm_mean, norm_sd, z_score, descriptor}`, `TAROM_degrees{...}`, `movement_duration_sec{...}`, `multivariate_coordination{mahalanobis_distance, threshold_p95, pathological_synergy_flag}`, `prompt_directives{score rank / compensation 검출 / narrative report}`.
- **VLM 실패 인용:** Li et al.(arXiv:2511.17727): *"zero-shot VLM이 **score flatlining** — 환자 중증도와 무관하게 거의 동일한 평균 점수 예측"*, pose keypoint도 2D bbox crop에만 사용(≈40% 상대오차).

### (L) 왜 바꿨나 — FMA→ARAT, 4과제→2과제 (세션·교수면담 문서 기록)

| 질문 | 답 |
|---|---|
| **왜 FMA → ARAT?** | ① RGB-D FMA-UE 자동채점은 **이미 임상검증 완료**(Brain Sci 2022 **PMID 36291314**, Clin Rehabil 2024 **PMID 38693881**) → 신규성 없음. ② FMA/ARAT는 **"우리가 만드는 점수"가 아니라 정답(임상 참조)** 으로 씀. ③ **"ARAT가 FMA보다 우수해서"가 아님**(그렇게 말하면 안 됨). |
| **왜 4과제 → 2과제?** | ① 운동학이 임상점수를 잘 가르는 구간은 **"완수 vs 실패"**(Unger 2026 AUC 0.96–0.99)이고 **2 vs 3점은 0.70–0.84로 낮음** → **pick-and-place 계열(ARAT 3·12번)** 로 좁힘. ② 물체 수↑ → 채점 지침·배치·치료사 교육·검정력 분산이 늘어남. ③ **Padilla-Magaña 2022가 ARAT 16활동을 이미 다룸** → 우리는 그보다 좁게. |
| **GMM은?** | 소표본 정상군집은 불안정 + 이미 선행(Padilla-Magaña·Jarque-Bou) → **본 실행 범위 제외**(§12.2 후속 과제). |

### (M) ⚠️ 이 시기가 「배경 메모의 GMM 6차원 · 14프레임」의 출처다

세션 기록에 당시 향후 계획이 그대로 남아 있다:
> *"[데이터 수집] 비장애인 기준 데이터셋(N=15) … **4개 과제 각 8회 반복** / [알고리즘 구현] **GMM 파지 군집화 및 이탈도 산출 모듈 코드화: 6차원 운동학 벡터 기반 비장애인 파지 서브타입 도출 및 장애인 매니폴드 투영** / [VLM] 5개 비교 조건(A0 수치학습 / A1 영상만 / A2 영상+수치 / A3 제안 / **A4 수치만**)"*

→ 즉 **과제 배경 메모(3번)의 "GMM 6차원 + 14프레임 + 서브타입 백분위"는 이 원래 계획(FMA-UE + 4과제)의 언어**이며, 현재 실행계획 v13.2와 다르다. **§0-2의 경고가 이 지점을 가리킨다.**

### (N) 궤적 요약

**4과제(FMA-UE, 8/26~9/2)** → **3-4과제 정제(9/4: 원통·구·측면집기 + 장갑 add-on, 맨손 신전 제외, A0~A4 조건)** → **2과제(ARAT 3·12, 9/22 Feynman 합류)** → **3과제(ARAT 3·12 + 머리 위 손, 10/1 교수 피드백)**.

| **"16활동은 이미 선행"** | **Padilla-Magaña 2022**(PMID 35632013) | CyberGlove로 **ARAT 16활동** 분류(SVM 97.8%) |
| **손가락 정밀 aperture 포기** | **Li Y 2022**(PMID 36291314) | D435+Leap+FSR로 FMA 30항목(r=.981) — **RealSense 손목 오차 평균 96mm** |

### (B) 논문별 상세 — 무엇을 했고, 그래서 우리가 무엇을 정했나

**① Jeannerod 1984** — *The timing of natural prehension movements*, J Motor Behavior · **PMID 15151851** · doi 10.1080/00222895.1984.10735319
- **한 일:** 사람이 물건을 집을 때 운동이 **운반(transport) + 파지(grasp) 두 성분**으로 나뉘고, 파지는 접촉 전에 손을 **최대로 벌렸다 닫는다**는 것을 최초 정량화. **최대 개구(MGA)** 는 물체 크기의 **≈1.2~1.5배**이고 이동 중·후반(≈70% 시점)에 정점.
- **우리가 정한 것:** ① **MGA Ratio**(`MGA / 손바닥 길이`)를 핵심 지표로. ② **구 직경 7.0 cm 선택** — 정상 MGA가 ≈8.5~10.5 cm로 예측되어, 뇌졸중의 **과소개구(hypometria, R<1.1)·과대개구(hypermetria, R>1.8)** 가 가장 잘 드러나는 임계 직경.

**② Lyle 1981** — *A performance test for assessment of upper limb function*, Int J Rehabil Res · **PMID 7333761** · doi 10.1097/00004356-198112000-00001
- **한 일:** **ARAT 원형**을 제안 — 19항목 · 4소검사(Grasp/Grip/Pinch/Gross) · 0~3점.
- **우리가 정한 것:** **원통 5.0 cm = ARAT Subtest 2(Grip) 표준 규격** 채택 → "우리 원통 과제는 ARAT Grip 표준을 준용"이라는 정당화. (이후 **Yozbatiran 2008**이 물성·채점을 표준화)

**③ Yozbatiran 2008** — ARAT 표준화 · **PMID 17704352** · doi 10.1177/1545968307305353
- **한 일:** ARAT의 **물체 물성·배치 좌표·시간 기준**을 수치화 — 블록 5 cm **55 g**, **구슬 ⌀1.6 cm 5.4 g**, **선반 37 cm**, **3점=5초 이내**, **"몸통이 등받이에서 완전히 떨어지면 2점"**, 낙하는 최선 수행 기준.
- **우리가 정한 것:** 현재 **T1 = ARAT 3번(블록)**, **T2 = ARAT 12번(구슬)** 의 정본. 체간(등받이 접촉)이 **채점 기준**임을 확인.

**④ Fugl-Meyer 1975** — *post-stroke hemiplegic patient. 1. method for evaluation of physical performance*, Scand J Rehabil Med · **PMID 1135616**
- **한 일:** **FMA 원논문** — 상지·하지·손 기능을 0~2점으로 평가하는 프로토콜. 손 파트에 **구형 파지(Spherical Grasp)** 항목 포함.
- **우리가 정한 것:** **구 7.0 cm = FMA-UE 손 파트 표준**(야구공/테니스공 6.5~7.0 cm). "FMA-UE 손 파트를 100% 대변"이라는 목표의 근거.

**⑤ ASSH 1983** — *The Hand: Examination and Diagnosis* (2nd ed.), Churchill Livingstone `[원문 인용]`
- **한 일:** 수부외과 표준으로 **TAM(Total Active Motion)** 정의 — 각 관절의 **굴곡 − 신전 결손의 합**.
- **우리가 정한 것:** **TAROM**(5지 합) — 정상 ≈450° vs 환자 <250°를 단일 척도로 요약.

**⑥ Balasubramanian 2015** — *On the analysis of movement smoothness* · **PMID 26651329** · doi 10.1186/s12984-015-0090-9
- **한 일:** 부드러움 지표 32개를 검토해 **무차원·시간불변**인 **SPARC**를 정립(`V̄=0.05`, `ωc_max=20π`, 적응적 컷오프).
- **우리가 정한 것:** **SPARC를 부드러움 주 지표**로. (단 0.2초 미만 미세지연은 못 잡음 → §부록 B 시계 버그 사건으로 연결)

**⑦ Chen 2025** — *Robot-Assisted Mirror Rehabilitation for Post-Stroke Upper Limbs: A Personalized Control Strategy*, Sensors 25(18):5659 · **PMID 41012897** · doi 10.3390/s25185659
- **한 일:** 건측 운동을 캡처해 환측 로봇을 제어하는 **마스터-슬레이브 미러테라피**. 그러나 **팔 전체 외골격 + sEMG 기반**(착용 부담), **수부 미세 지표 부재**.
- **우리가 정한 것:** **Task 4(공압 미러테라피)의 선례** + 우리 차별점 = **"수부 미세지표 + 로봇 중재를 단일 플랫폼에 통합"**.

**⑧ Amprimo 2024 (GMH-D)** — *Hand tracking for clinical applications: Validation of the Google MediaPipe Hand (GMH) and the depth-enhanced GMH-D frameworks*, Biomed Signal Process Control **96:106508** · **doi 10.1016/j.bspc.2024.106508** · OpenAlex **W4399350746** · arXiv:**2308.01088** *(2026-10-05 라이브 확인)*
> ⚠️ **정정:** 계획서 참고문헌은 이를 **"Ferraris, C., Amprimo, G., … 88, 105618"** 로 적었으나 → **제1저자는 Amprimo G**(Ferraris는 **마지막 저자**), **권·페이지는 96:106508**(88:105618 아님) = **3중 오류**.
- **한 일:** MediaPipe Hand에 RGB-D 깊이를 결합한 **GMH-D**를 만들어 **120 fps OptiTrack**과 동시 비교 → **손끝 거리·간격 시계열이 모션캡처와 높은 일치**.
- **우리가 정한 것:** **비접촉으로 손가락 수준 계측이 가능하다**는 정당화. 동시에 이 논문이 **"공백 주장 3개" 중 하나를 반박**한 원인(§2-1).

**⑨ Kim 2016** — Kinect+ANN FMA 추정, PLoS ONE 11(7):e0158640 · **PMID 27367518**
- **한 일:** Kinect로 FMA 13항목 채점(정확도 65–87%, 전체 FMA와 r=.799) — **상지 대동작 편중**, **블랙박스 분류**.
- **우리가 정한 것:** 차별점 = **손가락 미세운동 + 생체역학 설명가능성**(TAM/SPARC/MGA).

**⑩ Qiu 2022** — *Kinematic Measures of 3D Reach to Grasp...*, IEEE EMBC · **PMID 36086392** · doi 10.1109/EMBC48229.2022.9871891
- **한 일:** 아급성 8명 · 3시점 · 흉골 10 cm → 견봉 30 cm과제. **PAp(최대 파지 간격)·TPAp(최대 간격 도달 시점)·TAPV(최고속도→운반 시작)·RGC** 를 정의. **TPAp+PAp가 FMA 변동 59.8%**, **TAPV+TPAp 61.9%** 설명.
- **우리가 정한 것:** **피처 F1(최대간격)·F2(피크시간)의 조작적 정의** 근거(9/11 개정안). ⚠️ 개별 Pearson r은 원문 접근 불가로 인용 금지.

**⑪ Lang 2009** — *Recovery of thumb and finger extension and its relation to grasp performance after stroke*, J Neurophysiol 102(1):451–9 · **PMID 19458140** · doi 10.1152/jn.91310.2008 *(2026-10-05 라이브 확인)*
> 계획서의 **"Lang 2005"는 정확히 특정 못함** — 후보: **Lang 2006**(ARAT properties early after stroke, **PMID 17141640**) 또는 Lang 2007(**PMID 17558358**).
- **한 일:** 뇌졸중에서 **손가락별 자발적 신전(extension) 회복 궤적**이 파지 속도·간격과 독립적으로 회복됨 → **개별 손가락 펴기가 기능적 파지의 핵심**.
- **우리가 정한 것:** **F4(해제변화량/재개방)** 피처. 맨손 과제에서 **신전(폄) 능력**을 측정하는 이유.

**⑫ Unger 2026** — *Markerless Motion Capture in Routine Clinical Upper Limb Assessments*, arXiv:2607.23608
- **한 일:** 웹캠 3대(Brio 4K)를 **실제 임상 루틴 ARAT**에 삽입(20명, 1,174 trial). 재투영오차 12.5 px, **"완수 vs 실패" Tier1 AUC 0.91–1.00**, 팔꿈치 ROM r=.77–.93, **ARAT 포화 후에도 ≥15 pp 검출**. **smoothness는 의도적 제외**(카메라 수 적어 jitter 취약).
- **우리가 정한 것:** ① **"완수 vs 실패" 구간이 잘 갈린다 → ARAT 3·12번(pick-and-place) 집중.** ② **SPARC 정면 도전**(그들이 포기한 영역). ③ 체간·팔 ROM을 함께 볼 근거.

**⑬ Padilla-Magaña 2022** — *Quantitative Assessment of Hand Function ... with ARAT*, Sensors 22(10):3604 · **PMID 35632013**
- **한 일:** **CyberGlove II**로 **ARAT 16활동** 손 관절각 측정, SVM **97.8%**(전부 ARAT 2–3점 구간). 단 **Borderline-SMOTE 오버샘플링** + **나이 25년 차이** 교란.
- **우리가 정한 것:** "ARAT 16활동은 이미 다뤄졌다" → **우리는 2항목으로 좁혀 깊이**. 또한 **"ARAT로 정상-장애인 구분 불가"라는 주장 금지**(그들은 97.8%로 구분).

**⑭ Li Y 2022** — *Automated RGB-D Sensor-Based Measurement of FMA-UE*, Brain Sci 12(10):1380 · **PMID 36291314**
- **한 일:** D435 + **Leap Motion 200fps** + **FSR 5개**로 FMA 30항목 자동화(치료사 r=.981). 그런데 **RealSense가 본 손목 위치는 Vicon 대비 평균 96 mm 오차**.
- **우리가 정한 것:** **단일 RGB-D로 손가락 정밀 aperture를 주장하지 않는다**(구슬 ⌀16 mm vs 오차 96 mm). 그들은 **손을 Leap Motion으로 우회**했는데, 우리는 우회하지 않고 **한계를 명시**한다.

**⑮ Faity 2022** — *Validity and Reliability of Kinect v2 ... Seated Reaching*, Sensors 22(7):2735 · **PMID 35408349**
- **한 일:** Kinect v2(정면 1.5 m) vs Vicon 6대. **trunk displacement ICC .93 / shoulder .88** 는 좋으나 **trunk rotation .38 / NVP .38 / peak velocity .21** 로 실패.
- **우리가 정한 것:** **속도·미분 지표(peak velocity, NVP)를 삭제**하고, **믿을 수 있는 지표만** 남긴다(§G-7-bis 결정표).

### (G) 정답(Ground Truth) 근거 (원문 §3)

- **고니오미터**(수기/전자) = 14개 관절의 정적 굴곡각 정답 → **ICC(2,1) ≥ 0.85** + **Bland–Altman 95% LoA**
- **FMA-UE 손 파트(0~14점) + Brunnstrom Hand(1~6)** = 재활의학 전문의/물리치료사 **2인 독립** 측정 → AI 목표(RMSE < 1.2점, 분류 정확도 > 90%)
- **왜 3개 정답이 다른가:** 고니오미터 = **수치 정확도**의 정답 / FMA·Brunnstrom = **점수**의 정답 / 가림 주석 = **품질**의 정답 (→ §부록 A D-11로 계승)

## G-10. 선행연구가 공통으로 놓친 6개 공백 + 우리 차별점 5개

**공백 6개:**
1. **오차 → 판단 전파 사슬 미검증** — Li 2022는 96 mm 오차를 보고했지만 점수 영향은 안 봤고(r=.981은 오차 존재 하 값), Faity는 ICC 0.21을 보고했지만 판단 영향은 안 봤다.
2. **"영상만 vs 영상+수치" 통제 비교가 없다** — Li 2026 영상만(실패), Tang 2025 특징만(비장애), Xing 2025 정적 keyframe(성공했으나 동적 아님), xAARA는 운동학을 내부 표현으로만.
3. **품질 기반 입력 선별 전무** — Li 2022 SSA(시행선택 없음), Unger IQR×3.0 일괄, xAARA는 **출력** defer.
4. **0/1/2/3 전 구간 + 장애인 단위 분할 동시 충족 0편** — Ahmed 2025는 2·3만, segment 단위.
5. **무마커 임상환경에서 smoothness 검증 0편** — Faity 실패, Unger 의도적 제외, Bayle/Saes는 광학·전자기식. **RGB-D에서 SPARC·TAPV 0편**.
6. **손가락 수준(aperture·pinch) 골드스탠다드 검증 0편** — Padilla-Magaña는 장갑, Li 2022는 Leap으로 우회, Unger는 손가락 지표 없음.

**우리 차별점 5개:** ① 오차→판단 counterfactual(동일 영상·수치만 조작) ② 품질선택 + 동일개수 무작위 제거 대조군 ③ ARAT 3·12번 비접촉 계측 오차 최초 정량화(Faity 표를 뇌졸중·파지에서 재작성, SPARC·TAPV 정면 도전) ④ 4-class 전 구간 + 장애인 단위 CV ⑤ 카메라 사양 완전 공개.

**금지 주장 8개:** "ARAT 손과제 운동학 최초"(Padilla-Magaña) / "ARAT로 정상-장애인 구분 불가"(2–3점 SVM 97.8%) / "JSON·구조화 프롬프트 최초"(Tang·Xing) / "운동학+영상 결합 최초"(Unger·xAARA·BiomechGPT) / "불확실성·설명·보류 최초"(xAARA) / "포화 후 운동학 개선 검출 최초"(Unger ≥15 pp) / "GMM 정상 하위유형 최초"(Romero·Jarque-Bou) / "모든 VLM은 FMA 채점 실패"(Li 2026은 Qwen2.5-VL-72B+이 프로토콜 한정).

## H-4. 재현 방법 (다른 사람이 다시 하려면)

1. **DOI 일괄:** Europe PMC REST `search?query=DOI:"<doi1>" OR DOI:"<doi2>" …&format=json` (배치 8개 권장)
2. **PMC 미수록 DOI:** OpenAlex `works?filter=doi:<doi>` (예: MDPI MTI, Springer LNCS)
3. **arXiv:** `export.arxiv.org/api/query?id_list=<id1>,<id2>`
4. **고전 문헌:** PubMed `esearch` 제목 키워드 → `esummary`
5. **금지:** Crossref `works?query=<doi>` 는 **DOI 정확 조회에 부적합**(무관 레코드 반환 — 이번에 확인)
