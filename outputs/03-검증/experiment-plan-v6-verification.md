### 6-3. 의도적으로 데이터 후에 정하는 것 (미픽스가 아니라 설계된 슬롯)

| 항목 | 픽스된 것 | 데이터 후에 정하는 것 |
|---|---|---|
| Q1 유효 depth 임계값 | **선택 규칙**(balanced accuracy, 사람 단위 2-fold) | 임계값 숫자 |
| u (오염 단위) | **정의**(독립 기준 대비 P95 절대오차) + 폴백 사다리 + B안 | 실측값 |
| VLM revision | 모델명·디코딩·입력 형식 | 실제 revision hash |
| 시행 수 | 수집 5~15, 모델 평가 1–3회 | 달성치 |

→ 이 4개는 **사전등록으로 규칙을 먼저 고정**하므로 사후 조작이 아니다. 오히려 정직한 방법론이다.
