## 1. 연구 질문과 주 결과 (동결)

**한 문장 질문:** **품질로 선택한 수치**를 주면 VLM의 항목 채점 오차가 줄어드는가, 그리고 그 대가는 **과잉 보류**인가?

### 주 결과 2개 (확증적, Holm 보정)
| # | 비교 | 정의 | 왜 주 결과인가 |
|---|---|---|---|
| **PR-1** | **게이팅 효과** | `G_i = MAE_i(A2) − MAE_i(A3)` | **같은 영상·같은 라벨**에서 수치 집합만 다름 → 라벨 품질에 면역 + **개입의 인과 효과** |
| **PR-2** | **게이팅의 고유 가치** | `E_i = MAE_i(R) − MAE_i(A3)` | "숫자를 덜 보여준 탓"을 통제한 비교 |

**1급 기술 결과(검정 아님, 반드시 보고):** **보류율(A3)** · **(보류율, MAE) Pareto 곡선**(Q1 sweep, 컴퓨트 의존).

**Holm 보정**, 양측, α=0.05, **환자 단위** 대응. 부호 방향도 함께 보고한다.
**탐색적(보정 없음, CI·효과크기만):** `A2−A1`, `A3−A4`, A0/A0-time, 프레임 밀도, 설명 평가, **큰 오차(≥2점) 비율**, **bias_3u 기전(H5)**.

### 🚨 데이터 저장 필수 규칙 (2026-09-22 실측으로 발견)

| 규칙 | 내용 |
|---|---|
| **`cv2.imwrite` 금지** | OpenCV는 Windows에서 **비ASCII 경로에 조용히 실패**한다. **실측 검증:** 한글 포함 절대경로 → `False`(파일 없음) / 상대 ASCII 경로 → `True` / `imencode+tofile` → `True`. 우리 작업 폴더가 `바탕 화면`을 포함하므로 **깊이 프레임이 저장되지 않고 CSV만 남는다** |
| **우회 코드** | `ok, buf = cv2.imencode(".png", arr)` → `buf.tofile(path)` → 저장 후 `os.path.getsize(path) > 0` 확인. 실패하면 **예외를 올려라**(조용한 실패 금지) |
| **즉시 검증** | 매 세션 후 **`L0_raw/<trial>_depth/` 의 PNG 개수 == 프레임 수** 인지 확인. 불일치면 그 세션은 재촬영 |
| **타임스탬프 정밀도** | `t_s`를 **최소 6자리** 또는 정수 마이크로초로 저장. 4자리는 dt 양자화로 K2에 **~0.1% 편향**(합성 검증: 135.0000 → 135.1351) |

**7-3. u 확정 후 주입 방식 선택**

## 9. 실험 조건 A0~A4 + R (동결)

| 조건 | 입력 | 확인 |
|---|---|---|
| **A1** | RGB 영상(§10 프레임) + 과제 지침 + T | 기준선 |
| **A2** | A1 + **K1/K2 후보값 전체** | 숫자 추가 효과 |
| **A3** | A1 + **Q 통과한 K1/K2** | **게이팅 효과 (PR-1)** |
| **A4** | A3와 같은 수치·지침·시간, **RGB 제외** | 영상의 추가 가치 |
| **A0** | 로지스틱 회귀: K1·K2(시행 내 정규화)·Q 요약·T·과제 ID | 경량 통계모형 대조 |
| **A0-time** | T·과제 ID만 | 시간 단서만의 효과 |
| **R** | A2에서 A3와 **같은 양**을 품질과 무관하게 제거 | "숫자를 덜 보여준 탓" |

### R 조건 배정 알고리즘 (결정 22 종결)
```
for 지표 f in {K1, K2}:
    S_A3(f) = A3에서 f를 보류한 시행 집합
    n = |S_A3(f)|
    if n > 0.5 * N_trials:  해당 지표는 R 비교에서 제외하고 "정보 없음" 표시
    else:  R에서 보류할 시행을 (전체 시행 − S_A3(f)) 중에서 무작위로 n개 선택
원래 하드 결측은 모든 조건에서 결측 유지 (R에서도 복원 금지)
seed 3개: 20260922, 20260923, 20260924 → 환자별 결과를 평균
```
⚠️ R은 **평가용 대조**이며 배포용 알고리즘이 아니다.
⚠️ A3에서 아무것도/전부 보류했다면 **"이 비교의 정보가 없음"** 을 표시한다.

### 프롬프트 (모든 조건 동일 템플릿, 0-shot)
```
[과제 지침]  ARAT 항목 {N} ({물체}). 지시문: "{지시문}"
[채점 기준]  3 = 5초 이내 정상 수행 (올바른 손·팔 움직임, 자세 유지)
             2 = 완료했으나 5–60초 또는 큰 어려움
             1 = 60초 내 부분 수행
             0 = 60초 내 어떤 부분도 못함
[관찰 구간]  T = {T} 초
[운동학 수치]
  thumb_index_surface_p95_mm = {K1 또는 null}
  wrist_surface_speed_p95_mm_s = {K2 또는 null}
[지침]  null은 신뢰 가능한 추정이 없다는 뜻이며, 장애나 0값이 아니다.
[출력]  먼저 점수(0/1/2/3) 한 줄, 그 다음 최대 2문장의 근거.
```
⚠️ **A3에만 더 자세한 지침을 주지 않는다.** 조건별로 달라지는 것은 **수치의 유무·품질 선택뿐**이다.
⚠️ **조건명을 프롬프트에 쓰지 않는다.**

## 11. 오류 주입 (동결)

| 항목 | 값 |
|---|---|
| **bias** (상수 편향) | 해당 시행 값 전부에 **+1u / +3u** |
| **burst** (시행 단위 급등) | **한 시행의 값만 +3u**, 나머지 그대로 |
| 대상 | **A2, A3만** |
| 수준 | 원래 + 주입 4수준 = 5수준 |
| 실행 수 | 72영상 × 주입 4 × 2조건 = **576 출력** (원래 432 재사용) |

⚠️ **burst를 프레임 단위로 정의하지 않는다.** 3프레임 burst은 P95를 못 움직여(≤+2.6%) **모델 입력을 바꾸지 않는다 = 실험 무효**.
⚠️ `u / 기저 P95 > 0.10` 인 지표에는 **"이미 오염" 라벨**을 붙인다.

## 13. 분석 계획 (동결)

| 구분 | 내용 |
|---|---|
| **분석 단위** | **환자.** 12명이 독립 표본. 72영상·주입본은 **반복 관측** |
| **PR-1** | `G_i = MAE_i(A2) − MAE_i(A3)` **(게이팅 효과)**, 환자 단위 대응, **Holm** |
| **PR-2** | `E_i = MAE_i(R) − MAE_i(A3)` **(게이팅의 고유 가치)**, 환자 단위 대응, **Holm** |
| **1급 기술** | **보류율(A3)** + **(보류율, MAE) Pareto**(Q1 sweep, 컴퓨트 의존) |
| **탐색적** | `A2−A1`, `A3−A4`, A0/A0-time, 프레임 밀도 층화, 설명 평가, **큰 오차(≥2점) 비율**, **bias_3u 기전(H5)** |
| **구간** | **환자 단위 bootstrap**(10,000회, seed 고정) |
| **추가** | 정확일치율, 선형 가중 κ, 과제별 혼동행렬, **0–1→3 과대평가 수와 분모**, 수치 가용률, 추적 실패를 잘못 수용한 비율, **반복 시행 간 변이**, **시행 순서 추세** |
| **실패 처리** | 기술적 재시도 **1회**. 실패를 제거하지 않는다. **손실 = 3**(0–3 척도의 최대 절대오차)으로 대체해 "실패 포함 손실" + 유효 MAE + 출력 성공률을 함께 보고. **실패를 0점으로 바꾸지 않는다** |
| **두 평가자** | 현장·독립 각각에 대해 MAE 산출. **불일치 시행은 "라벨 불확실"로 별도 집계** |

### 다중비교 전략 (R8 종결)
- **확증적 = PR-1, PR-2 두 개.** Holm 보정(α=0.05).
- **나머지 전부 탐색적:** 보정 없이 **CI와 효과크기만** 보고하고 **표·그림 제목에 "탐색적"** 표기.
- **"유의성 한 개"로 결론을 만들지 않는다.** 주 결과가 CI를 0 포함하면 **"이 표본에서 방향 확인 안 됨"** 으로 쓴다.

## 14. 판정표 (동결)

| 관측 | 허용되는 결론 |
|---|---|
| **PR-1 유의 (A3 < A2)** | 이 표본·과제에서 **품질 게이팅이 채점 오차를 줄임** |
| **PR-1 비유의 (A3 ≈ A2)** | 이 표본에서 **게이팅의 채점 개선을 확인하지 못함** |
| **PR-2 유의 (A3 < R)** | **게이팅의 고유 가치 확인** — "숫자를 덜 봐서"가 아니라 **품질 규칙이 기여** |
| **PR-2 비유의 (A3 ≈ R)** | 이득이 **정보량 감소 효과로 설명될 수 있음** → 고유 기여 미확인 |
| **보류율 높음 + PR-1 유의** | 이득은 있으나 **좁은 구간에서만** 성립 → 보류–정확도 절충으로 보고 |
| **보류율 높음 + PR-1 비유의** | **과잉 보류가 대가만 남김.** 게이팅이 실용적으로 무익 |
| **큰 오차(≥2점) 비율이 A3에서 감소** | 평균이 아니라 **위험 감소** (탐색적) |
| A0/A4가 더 좋음 | **VLM 영상 입력의 추가 가치는 입증 안 됨** |

⚠️ **어느 칸이든 "VLM이 임상 채점을 대체한다"고 쓰지 않는다.**
⚠️ `flatlining`은 **현상명**, `kinematic blindness`는 **우리가 붙인 해석적 명칭**이지 표준 용어가 아니다.
